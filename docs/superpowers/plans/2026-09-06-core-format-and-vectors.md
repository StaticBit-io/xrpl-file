# xrpl-file Step 1: Format, Core, Browser Library and Shared Vectors — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A .NET library and a dependency-free browser library that parse `xrpl-file://` links, read and verify files out of XRPL memos, write files into them, and agree byte for byte through shared test vectors — plus the normative format document.

**Architecture:** `XrplFile.Core` is a pure library on top of the `Xrpl` NuGet package: link, Merkle tree, block list and manifest codecs know nothing about the network; a small `ILedgerSource` / `ILedgerSink` pair is the only thing that talks to a node, so the reader and writer are tested against in-memory fakes and only once against a standalone rippled. `web/xrpl-file.js` mirrors the reading half rule for rule in ESM. `tests/vectors/v1.json`, generated by a console tool from the C# code, is asserted by both test suites; the JavaScript side is the independent check on the C# side.

**Tech Stack:** .NET 10 SDK 10.0.303, C# latest, `Xrpl` 11.2.0, `xunit.v3` 4.0.0 with built-in `Assert` (test projects are executables — see Global Constraints), Node 24 (`node --test`, global `WebSocket` and WebCrypto), Docker Compose for the standalone rippled stand.

**Spec:** `docs/superpowers/specs/2026-09-05-xrpl-file-design.md` — sections 1–5 and 7–8 are implemented here; section 6 (CLI, gateway, page, element) is for later plans.

- **`dotnet test` does not work with xunit.v3 on the .NET 10 SDK** ("Testing with VSTest target is no longer supported"). - Chunk payload is **1000** bytes under marker `xf/c/<i>`; block list payload is **982** bytes under `xf/b/<j>` + `MemoFormat` `application/json`; manifest payload is **995** bytes under `xf/m` + `MemoFormat` `application/json`. Markers carry a decimal index without leading zeros, up to 12 digits.
- Merkle: leaf `sha256(0x00 || bytes)`, node `sha256(0x01 || left || right)`, unpaired element promoted (never duplicated), blocks of **1024** chunks. Hex is upper case on output, case-insensitive on input.
- Link form is `xrpl-file://<network>/<64 hex>`; `network` is `mainnet`, `testnet`, `devnet` or a decimal NetworkID; nothing else in the link.
- The reader returns a whole file and refuses anything above `MaxBytes` (default **20 000 000** bytes) before reading a chunk.
- Standalone node for integration tests: `.ci-config/docker-compose.ci.yml` copied from `E:\GIT\XRPL\XrplCSharp\.ci-config\` (image `xrpllabsofficial/xrpld:3.3.0`, admin WebSocket `ws://localhost:6006`, genesis seed `snoPBrXtMeMyMHUVTgbuqAfg1SUTb`, `ledger_accept` every 4 s). The synthetic ledger used by both test suites (defined in `tools/XrplFile.Vectors/Program.cs`, repeated in `Vectors.cs` and `web/test/vectors.mjs`): chunk `i` sits in ledger `1000 + floor(i / 100)`; block `j` therefore starts in ledger `1000 + floor(1024·j / 100)`; every list memo sits in ledger `lastChunkLedger + 1`; the manifest sits one ledger after the last chunk or list; `ledgers = [1000, lastChunkLedger]` for one block and `[1000, lastChunkLedger + 1]` otherwise. Transaction hashes are `SHA256("chunk:" + i)`, `SHA256("list:" + j)`, `SHA256("manifest")`, upper hex. `src/XrplFile.Core/XrplFileLink.cs`:
```csharp
using System.Diagnostics.CodeAnalysis;

namespace XrplFile;

/// <summary>
/// <c>xrpl-file://&lt;network&gt;/&lt;tx-hash&gt;</c>: the hash of the manifest transaction on a named network.
/// Nothing else is in the link; the MIME type, size and name live in the manifest.
/// </summary>
public sealed record XrplFileLink
{
    public const string Scheme = "xrpl-file";

    private const string Prefix = Scheme + "://";
    private const int HashLength = 64;

    private static readonly HashSet<string> KnownNetworks = new(StringComparer.Ordinal) { "mainnet", "testnet", "devnet" };

    public string Network { get; }

    public string TxHash { get; }

    public XrplFileLink(string network, string txHash)
    {
        Network = NormalizeNetwork(network)
            ?? throw new XrplFileException(XrplFileError.InvalidLink, $"'{network}' is neither a network name nor a NetworkID");
        TxHash = NormalizeHash(txHash)
            ?? throw new XrplFileException(XrplFileError.InvalidLink, "the transaction hash is not 64 hexadecimal characters");
    }

    public static XrplFileLink Parse(string text)
    {
        if (text is null || !text.StartsWith(Prefix, StringComparison.OrdinalIgnoreCase))
        {
            throw new XrplFileException(XrplFileError.InvalidLink, $"an xrpl-file link starts with '{Prefix}'");
        }

        string rest = text.Substring(Prefix.Length);
        int slash = rest.IndexOf('/');

        if (slash <= 0 || slash == rest.Length - 1)
        {
            throw new XrplFileException(XrplFileError.InvalidLink, "an xrpl-file link is the network, a slash and the manifest transaction hash");
        }

        return new XrplFileLink(rest.Substring(0, slash), rest.Substring(slash + 1));
    }

    public static bool TryParse(string? text, [NotNullWhen(true)] out XrplFileLink? link)
    {
        try
        {
            link = Parse(text!);
            return true;
        }
        catch (XrplFileException)
        {
            link = null;
            return false;
        }
    }

    public override string ToString() => Prefix + Network + "/" + TxHash;

    private static string? NormalizeNetwork(string network)
    {
        if (string.IsNullOrEmpty(network)) return null;

        string lower = network.ToLowerInvariant();
        if (KnownNetworks.Contains(lower)) return lower;

        // Any other network is named by its NetworkID: digits only, no sign, no leading zero.
        bool digits = lower.All(character => character is >= '0' and <= '9');
        return digits && (lower.Length == 1 || lower[0] != '0') ? lower : null;
    }

    private static string? NormalizeHash(string hash)
    {
        if (hash is null || hash.Length != HashLength) return null;

        foreach (char character in hash)
        {
            if (!Uri.IsHexDigit(character)) return null;
        }

        return hash.ToUpperInvariant();
    }
}
```

```csharp
/// The hash tree a file's identity is built from.
///
/// Leaves and nodes hash in different domains: a leaf is SHA256(0x00 ‖ data), a node is
/// SHA256(0x01 ‖ left ‖ right). Without the prefix, sixty-four bytes of payload hash to the same
/// value as the node over their two halves. An unpaired element at an odd level is carried up
/// alone, never paired with a copy of itself: with the copy, [a, b, c] and [a, b, c, c] share a root.
/// </summary>
public static class MerkleTree
{
    public const int HashBytes = 32;

    private const byte LeafPrefix = 0x00;
    private const byte NodePrefix = 0x01;

    public static byte[] Leaf(ReadOnlySpan<byte> data)
    {
        byte[] prefixed = new byte[1 + data.Length];
        prefixed[0] = LeafPrefix;
        data.CopyTo(prefixed.AsSpan(1));
        return SHA256.HashData(prefixed);
    }

    public static byte[] Node(ReadOnlySpan<byte> left, ReadOnlySpan<byte> right)
    {
        byte[] prefixed = new byte[1 + left.Length + right.Length];
        prefixed[0] = NodePrefix;
        left.CopyTo(prefixed.AsSpan(1));
        right.CopyTo(prefixed.AsSpan(1 + left.Length));
        return SHA256.HashData(prefixed);
    }

    /// <summary>The root over these hashes, in this order.</summary>
    public static byte[] Root(IReadOnlyList<byte[]> hashes)
    {
        if (hashes.Count == 0)
        {
            throw new ArgumentException("a tree needs at least one leaf", nameof(hashes));
        }

        List<byte[]> level = [.. hashes];

        while (level.Count > 1)
        {
            List<byte[]> next = new((level.Count + 1) / 2);

            for (int i = 0; i + 1 < level.Count; i += 2)
            {
                next.Add(Node(level[i], level[i + 1]));
            }

            if (level.Count % 2 == 1)
            {
                next.Add(level[^1]);
            }

            level = next;
        }

        return level[0];
    }
}
```

```csharp
using System.Text;

namespace XrplFile;

/// <summary>
/// How the three memo kinds are laid out and how much each may carry.
///
/// rippled refuses a transaction whose serialized Memos array exceeds 1024 bytes. A memo with
/// only MemoData costs 5 bytes of framing, which leaves 1019; a MemoType or MemoFormat costs 2
/// bytes of framing plus its own length. The budgets below follow from that and were confirmed
/// on a standalone node: each kind is accepted at its budget and refused one byte over.
/// </summary>
public static class MemoLayout
{
    public const int MaxMemoBytes = 1019;
    public const int MemoTypeFraming = 2;
    public const int MaxIndexDigits = 12;

    /// <summary>"xf/c/" or "xf/b/" plus up to twelve digits.</summary>
    public const int MaxMarkerBytes = 5 + MaxIndexDigits;

    public const string ManifestMarker = "xf/m";
    public const string JsonFormat = "application/json";

    public const int ChunkBytes = MaxMemoBytes - MemoTypeFraming - MaxMarkerBytes;
    public const int ListBytes = ChunkBytes - MemoTypeFraming - 16;
    public const int ManifestBytes = MaxMemoBytes - MemoTypeFraming - 4 - MemoTypeFraming - 16;

    private const string ChunkPrefix = "xf/c/";
    private const string ListPrefix = "xf/b/";

    public static string ManifestMarkerHex { get; } = Utf8Hex(ManifestMarker);

    public static string JsonFormatHex { get; } = Utf8Hex(JsonFormat);

    public static string ChunkMarkerHex(long index) => IndexedMarkerHex(ChunkPrefix, index);

    public static string ListMarkerHex(long index) => IndexedMarkerHex(ListPrefix, index);

    public static long? ChunkIndexOf(string? memoTypeHex) => IndexOf(memoTypeHex, ChunkPrefix);

    public static long? ListIndexOf(string? memoTypeHex) => IndexOf(memoTypeHex, ListPrefix);

    public static bool IsManifest(string? memoTypeHex) =>
        memoTypeHex is not null && string.Equals(TryDecode(memoTypeHex), ManifestMarker, StringComparison.Ordinal);

    public static string Utf8Hex(string text) => Convert.ToHexString(Encoding.UTF8.GetBytes(text));

    public static string FromHexUtf8(string hex) => Encoding.UTF8.GetString(Convert.FromHexString(hex));

    public static string Hex(ReadOnlySpan<byte> bytes) => Convert.ToHexString(bytes);

    public static byte[] Bytes(string hex) => Convert.FromHexString(hex);

    private static string IndexedMarkerHex(string prefix, long index)
    {
        if (index < 0)
        {
            throw new ArgumentOutOfRangeException(nameof(index), index, "a memo index is never negative");
        }

        string marker = prefix + index.ToString(System.Globalization.CultureInfo.InvariantCulture);

        if (marker.Length > MaxMarkerBytes)
        {
            throw new ArgumentOutOfRangeException(nameof(index), index, $"an index past {MaxIndexDigits} digits does not fit its memo");
        }

        return Utf8Hex(marker);
    }

    /// <summary>
    /// The index a marker carries, or null when it is not one. Strict on purpose: a leading
    /// zero, a sign or a stray character is somebody else's memo, not a chunk with a quirk.
    /// </summary>
    private static long? IndexOf(string? memoTypeHex, string prefix)
    {
        if (string.IsNullOrEmpty(memoTypeHex)) return null;

        string? marker = TryDecode(memoTypeHex);
        if (marker is null || !marker.StartsWith(prefix, StringComparison.Ordinal)) return null;

        string digits = marker.Substring(prefix.Length);
        if (digits.Length == 0 || digits.Length > MaxIndexDigits) return null;
        if (digits.Length > 1 && digits[0] == '0') return null;

        foreach (char character in digits)
        {
            if (character is < '0' or > '9') return null;
        }

        return long.Parse(digits, System.Globalization.CultureInfo.InvariantCulture);
    }

    private static string? TryDecode(string hex)
    {
        try
        {
            return FromHexUtf8(hex);
        }
        catch (FormatException)
        {
            return null;
        }
    }
}
```

`src/XrplFile.Core/FileTree.cs`:
```csharp
using System.Text;
using System.Text.Json;

namespace XrplFile;

/// <summary>One block of a file as its published list describes it.</summary>
/// <param name="Index">The block's position; block 0 holds chunks 0 to 1023.</param>
/// <param name="HashHex">The Merkle root over the block's chunk leaves, upper-case hex.</param>
/// <param name="FirstLedger">The ledger holding the block's first chunk — where a reader starts paging for this block.</param>
public sealed record BlockEntry(int Index, string HashHex, long FirstLedger);

/// <summary>
/// The two-level tree that is a file's identity: chunks group into blocks of 1024, a block hashes
/// to the root over its chunk leaves, the file hashes to the root over the block hashes in order.
/// Two levels so that any block can be verified on its own against the published list.
/// </summary>
public static class FileTree
{
    public const int BlockChunks = 1024;

    public static int BlockOf(long chunkIndex) => (int)(chunkIndex / BlockChunks);

    public static int BlockCount(long chunkCount) =>
        chunkCount <= 0 ? 0 : (int)((chunkCount + BlockChunks - 1) / BlockChunks);

    public static long ChunkCount(long size, int chunkBytes) =>
        size <= 0 ? 0 : (size + chunkBytes - 1) / chunkBytes;

    public static IReadOnlyList<byte[]> Split(ReadOnlyMemory<byte> file, int chunkBytes)
    {
        List<byte[]> chunks = new((int)ChunkCount(file.Length, chunkBytes));

        for (int at = 0; at < file.Length; at += chunkBytes)
        {
            chunks.Add(file.Slice(at, Math.Min(chunkBytes, file.Length - at)).ToArray());
        }

        return chunks;
    }

    public static byte[] BlockHash(IReadOnlyList<byte[]> chunks) =>
        MerkleTree.Root([.. chunks.Select(chunk => MerkleTree.Leaf(chunk))]);

    public static string RootHex(IReadOnlyList<BlockEntry> entries) =>
        Convert.ToHexString(MerkleTree.Root(
            [.. entries.OrderBy(entry => entry.Index).Select(entry => Convert.FromHexString(entry.HashHex))]));

    /// <summary>The list cut into memo-sized JSON payloads, greedily.</summary>
    public static IReadOnlyList<string> EncodeEntries(IReadOnlyList<BlockEntry> entries)
    {
        List<string> payloads = [];
        List<Wire> current = [];

        foreach (BlockEntry entry in entries)
        {
            Wire wire = new(entry.Index, entry.HashHex, entry.FirstLedger);
            current.Add(wire);

            if (Encoding.UTF8.GetByteCount(Serialize(current)) > MemoLayout.ListBytes)
            {
                current.RemoveAt(current.Count - 1);
                payloads.Add(Serialize(current));
                current = [wire];
            }
        }

        if (current.Count > 0) payloads.Add(Serialize(current));

        return payloads;
    }

    /// <summary>
    /// The list back from its memos, in index order, or a FormatException. Refused rather than
    /// repaired: a gap, a duplicate or a malformed hash means this is not the list the root was
    /// computed over.
    /// </summary>
    public static IReadOnlyList<BlockEntry> DecodeEntries(IEnumerable<string> payloads)
    {
        List<BlockEntry> entries = [];

        foreach (string payload in payloads)
        {
            Wire[]? wires;

            try
            {
                wires = JsonSerializer.Deserialize<Wire[]>(payload);
            }
            catch (JsonException e)
            {
                throw new FormatException("a block-list memo is not a JSON array of entries", e);
            }

            foreach (Wire wire in wires ?? [])
            {
                if (wire.h is null || wire.h.Length != MerkleTree.HashBytes * 2 || !wire.h.All(Uri.IsHexDigit))
                {
                    throw new FormatException($"block {wire.i} carries a hash that is not 32 bytes of hex");
                }

                entries.Add(new BlockEntry(wire.i, wire.h.ToUpperInvariant(), wire.l));
            }
        }

        if (entries.Count == 0) throw new FormatException("the block list is empty");

        entries.Sort((a, b) => a.Index.CompareTo(b.Index));

        for (int expected = 0; expected < entries.Count; expected++)
        {
            if (entries[expected].Index != expected)
            {
                throw new FormatException(
                    $"the block list is not 0..{entries.Count - 1}: found {entries[expected].Index} where {expected} was expected");
            }
        }

        return entries;
    }

    private static string Serialize(List<Wire> wires) => JsonSerializer.Serialize(wires);

    /// <summary>The shape on the wire. Single letters because every byte here is a memo byte.</summary>
    private sealed record Wire(int i, string h, long l);
}
```

`src/XrplFile.Core/Manifest.cs`:
```csharp
using System.Text;
using System.Text.Json;

namespace XrplFile;

/// <summary>
/// The one transaction an xrpl-file link points at: everything a reader needs to locate, order
/// and verify the bytes. Written last, because it names the ledger range the chunks occupy.
/// </summary>
/// <param name="Type">MIME type of the file.</param>
/// <param name="Size">File length in bytes.</param>
/// <param name="Chunk">Chunk payload size the writer used; this library writes MemoLayout.ChunkBytes and reads any value up to it.</param>
/// <param name="Root">Merkle root over the chunks, upper-case hex.</param>
/// <param name="FirstLedger">First validated ledger holding a chunk.</param>
/// <param name="LastLedger">Last validated ledger holding a chunk or a block-list memo.</param>
/// <param name="Blocks">Number of Merkle blocks.</param>
/// <param name="Lists">Number of block-list memos; zero when there is one block.</param>
/// <param name="Name">Optional file name.</param>
public sealed record Manifest(
    string Type,
    long Size,
    int Chunk,
    string Root,
    long FirstLedger,
    long LastLedger,
    int Blocks,
    int Lists,
    string? Name)
{
    public const int Version = 1;

    public long ChunkCount => FileTree.ChunkCount(Size, Chunk);

    /// <summary>
    /// The manifest as JSON that fits its memo. Every field but the name is fixed in size; a
    /// name that does not fit is cut to the longest UTF-8 prefix that does, and dropped when
    /// not even one character fits. A file is never refused over its name.
    /// </summary>
    public string Encode()
    {
        string? name = Name;

        while (true)
        {
            string json = Serialize(name);

            if (Encoding.UTF8.GetByteCount(json) <= MemoLayout.ManifestBytes) return json;

            if (string.IsNullOrEmpty(name))
            {
                throw new InvalidOperationException("the manifest does not fit its memo even without a name");
            }

            name = ShortenByOneCharacter(name);
            if (name.Length == 0) name = null;
        }
    }

    public static Manifest Decode(string json)
    {
        try
        {
            using JsonDocument document = JsonDocument.Parse(json);
            JsonElement root = document.RootElement;

            if (root.ValueKind != JsonValueKind.Object) throw new FormatException("the manifest is not a JSON object");

            if (Int(root, "v") is not { } version) throw new FormatException("the manifest has no version");
            if (version != Version) throw new FormatException($"manifest version {version} is not one this library reads");

            string type = Text(root, "type") ?? throw new FormatException("the manifest has no type");
            long size = Long(root, "size") ?? throw new FormatException("the manifest has no size");
            int chunk = Int(root, "chunk") ?? throw new FormatException("the manifest has no chunk size");
            string rootHex = Text(root, "root") ?? throw new FormatException("the manifest has no root");
            int blocks = Int(root, "blocks") ?? throw new FormatException("the manifest has no block count");
            int lists = Int(root, "lists") ?? throw new FormatException("the manifest has no list count");

            if (rootHex.Length != MerkleTree.HashBytes * 2 || !rootHex.All(Uri.IsHexDigit))
            {
                throw new FormatException("the manifest root is not 64 hex characters");
            }

            if (!root.TryGetProperty("ledgers", out JsonElement ledgers)
                || ledgers.ValueKind != JsonValueKind.Array
                || ledgers.GetArrayLength() != 2)
            {
                throw new FormatException("the manifest ledgers are not a pair");
            }

            if (!ledgers[0].TryGetInt64(out long first) || !ledgers[1].TryGetInt64(out long last) || first <= 0 || last < first)
            {
                throw new FormatException("the manifest ledger range is not ascending");
            }

            return new Manifest(type, size, chunk, rootHex.ToUpperInvariant(), first, last, blocks, lists, Text(root, "name"));
        }
        catch (JsonException e)
        {
            throw new FormatException($"the manifest does not parse as JSON: {e.Message}", e);
        }
    }

    /// <summary>Why the counts do not agree with one another, or null when they do.</summary>
    public string? Inconsistency()
    {
        if (Size < 0) return $"the size {Size} is negative";
        if (Chunk <= 0 || Chunk > MemoLayout.ChunkBytes) return $"a chunk of {Chunk} bytes is outside 1..{MemoLayout.ChunkBytes}";
        if (Lists < 0) return $"the list count {Lists} is negative";

        int expectedBlocks = FileTree.BlockCount(ChunkCount);
        if (Blocks != expectedBlocks) return $"the manifest says {Blocks} blocks, {ChunkCount} chunks make {expectedBlocks}";

        if ((Lists == 0) != (Blocks == 1)) return $"the manifest says {Blocks} blocks and {Lists} list memos, and a single block is the only file without a list";

        return null;
    }

    private string Serialize(string? name)
    {
        using MemoryStream stream = new();
        using (Utf8JsonWriter writer = new(stream, new JsonWriterOptions { Encoder = System.Text.Encodings.Web.JavaScriptEncoder.UnsafeRelaxedJsonEscaping }))
        {
            writer.WriteStartObject();
            writer.WriteNumber("v", Version);
            writer.WriteString("type", Type);
            writer.WriteNumber("size", Size);
            writer.WriteNumber("chunk", Chunk);
            writer.WriteString("root", Root);
            writer.WriteStartArray("ledgers");
            writer.WriteNumberValue(FirstLedger);
            writer.WriteNumberValue(LastLedger);
            writer.WriteEndArray();
            writer.WriteNumber("blocks", Blocks);
            writer.WriteNumber("lists", Lists);
            if (name is not null) writer.WriteString("name", name);
            writer.WriteEndObject();
        }

        return Encoding.UTF8.GetString(stream.ToArray());
    }

    /// <summary>One character off the end — a whole one, so a surrogate pair is not cut in half.</summary>
    private static string ShortenByOneCharacter(string value)
    {
        int cut = value.Length - 1;
        if (cut > 0 && char.IsLowSurrogate(value[cut])) cut--;
        return value.Substring(0, cut);
    }

    private static string? Text(JsonElement element, string name) =>
        element.TryGetProperty(name, out JsonElement value) && value.ValueKind == JsonValueKind.String ? value.GetString() : null;

    private static int? Int(JsonElement element, string name) =>
        element.TryGetProperty(name, out JsonElement value) && value.ValueKind == JsonValueKind.Number && value.TryGetInt32(out int number)
            ? number
            : null;

    private static long? Long(JsonElement element, string name) =>
        element.TryGetProperty(name, out JsonElement value) && value.ValueKind == JsonValueKind.Number && value.TryGetInt64(out long number)
            ? number
            : null;
}
```

`UnsafeRelaxedJsonEscaping` keeps `/` in `image/png` unescaped, which is what the documented example and the platform's encoder emit.

```csharp
using System.Security.Cryptography;
using System.Text;

namespace XrplFile;

/// <summary>
/// A deterministic byte stream both test suites regenerate instead of storing megabytes of
/// fixtures: block k is SHA256(seed ‖ k as a big-endian uint32), blocks concatenated, cut to size.
/// </summary>
public static class VectorStream
{
    public static byte[] Bytes(string seed, long size)
    {
        if (size < 0) throw new ArgumentOutOfRangeException(nameof(size));

        byte[] seedBytes = Encoding.UTF8.GetBytes(seed);
        byte[] input = new byte[seedBytes.Length + 4];
        seedBytes.CopyTo(input, 0);

        byte[] output = new byte[size];
        long at = 0;
        uint counter = 0;

        while (at < size)
        {
            input[^4] = (byte)(counter >> 24);
            input[^3] = (byte)(counter >> 16);
            input[^2] = (byte)(counter >> 8);
            input[^1] = (byte)counter;

            byte[] block = SHA256.HashData(input);
            int take = (int)Math.Min(block.Length, size - at);
            Array.Copy(block, 0, output, at, take);

            at += take;
            counter++;
        }

        return output;
    }
}
```

```csharp
using System.Text;
using System.Text.Json;
using System.Text.Json.Serialization;
using XrplFile;

// Writes tests/vectors/v1.json from the library's own code. The JavaScript suite checks the same
// file with an independent implementation, which is what makes the vectors a cross-check rather
// than a tautology. Usage: dotnet run --project tools/XrplFile.Vectors -- tests/vectors/v1.json

string output = args.Length > 0 ? args[0] : Path.Combine("tests", "vectors", "v1.json");

long[] sizes = [1, 999, 1000, 1001, 1024000, 1024001, 2500500];

static byte[] Leaf(string text) => MerkleTree.Leaf(Encoding.UTF8.GetBytes(text));

Dictionary<string, string> leafRoots = new();
foreach (int count in new[] { 1, 3, 5, 1025 })
{
    List<byte[]> leaves = [.. Enumerable.Range(0, count).Select(i => Leaf($"leaf-{i}"))];
    leafRoots[count.ToString()] = Convert.ToHexString(MerkleTree.Root(leaves));
}

List<byte[]> fiveChunks = [.. Enumerable.Range(0, 5).Select(i => Encoding.UTF8.GetBytes($"chunk-{i}".PadRight(MemoLayout.ChunkBytes, 'x')))];
List<BlockEntry> threeEntries = [.. Enumerable.Range(0, 3).Select(i => new BlockEntry(i, Convert.ToHexString(MerkleTree.Leaf([(byte)i])), 1000 + i * 40))];

Merkle merkle = new(leafRoots, Convert.ToHexString(FileTree.BlockHash(fiveChunks)), FileTree.RootHex(threeEntries));

List<FileVector> files = [];

foreach (long size in sizes)
{
    string seed = $"xrpl-file/v1/{size}";
    byte[] bytes = VectorStream.Bytes(seed, size);
    IReadOnlyList<byte[]> chunks = FileTree.Split(bytes, MemoLayout.ChunkBytes);
    int blocks = FileTree.BlockCount(chunks.Count);

    const long first = 1000;
    long lastChunkLedger = first + (chunks.Count - 1) / 100;
    long? listLedger = blocks > 1 ? lastChunkLedger + 1 : null;
    long last = listLedger ?? lastChunkLedger;
    long manifestLedger = last + 1;

    List<long> blockLedgers = [];
    List<BlockEntry> entries = [];
    List<string> blockHashes = [];

    for (int block = 0; block < blocks; block++)
    {
        List<byte[]> members = [.. chunks.Skip(block * FileTree.BlockChunks).Take(FileTree.BlockChunks)];
        string hash = Convert.ToHexString(FileTree.BlockHash(members));
        long ledger = first + (1024L * block) / 100;

        blockHashes.Add(hash);
        blockLedgers.Add(ledger);
        entries.Add(new BlockEntry(block, hash, ledger));
    }

    string root = FileTree.RootHex(entries);
    IReadOnlyList<string> lists = blocks > 1 ? FileTree.EncodeEntries(entries) : [];

    Manifest manifest = new(
        "application/octet-stream", size, MemoLayout.ChunkBytes, root, first, last, blocks, lists.Count, $"vector-{size}.bin");

    files.Add(new FileVector(
        seed, size, Convert.ToHexString(SHA256.HashData(bytes)), MemoLayout.ChunkBytes, chunks.Count, blocks,
        blockHashes, root, new Ledger(first, last, blockLedgers, listLedger, manifestLedger), lists, manifest.Encode()));
}

JsonSerializerOptions options = new()
{
    WriteIndented = true,
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
    DefaultIgnoreCondition = JsonIgnoreCondition.Never,
};

Directory.CreateDirectory(Path.GetDirectoryName(Path.GetFullPath(output))!);
File.WriteAllText(output, JsonSerializer.Serialize(new VectorSet(1, merkle, files), options) + "\n");
Console.WriteLine($"wrote {files.Count} file vectors to {output}");

    string Seed, long Size, string Sha256, int Chunk, long Chunks, int Blocks,
```

```csharp
using System.Runtime.CompilerServices;
using System.Text.Json;
using Xrpl.Client;
using Xrpl.Client.Exceptions;
using Xrpl.Client.Json;
using Xrpl.Models.Methods;

namespace XrplFile;

/// <summary>
/// ILedgerSource over the SDK's client. Answers are read as raw JSON rather than through the
/// SDK's typed models, so both api_version shapes parse and a field the models lack is not lost.
/// </summary>
public sealed class XrplClientLedgerSource(IXrplClient client, int pageSize = 400) : ILedgerSource
{
    private readonly IXrplClient _client = client;
    private readonly int _pageSize = pageSize;

    public async Task<LedgerTransaction?> TransactionAsync(string hash, CancellationToken cancellationToken)
    {
        JsonElement answer;

        try
        {
            XrplResponse<object> response = await _client.GRequest<object, TxRequest>(new TxRequest(hash), cancellationToken).ConfigureAwait(false);
            answer = response.Raw.ToJsonElement();
        }
        catch (Exception e) when (e is not OperationCanceledException
            && string.Equals(e.Classify().RawError, XrplErrorCodes.TxnNotFound, StringComparison.Ordinal))
        {
            return null;
        }

        if (answer.TryGetProperty("error", out JsonElement error)
            && string.Equals(error.GetString(), XrplErrorCodes.TxnNotFound, StringComparison.Ordinal))
        {
            return null;
        }

        return ParseRecord(answer);
    }

    public async IAsyncEnumerable<LedgerTransaction> AccountTransactionsAsync(
        string account, long fromLedger, long toLedger, bool forward, [EnumeratorCancellation] CancellationToken cancellationToken)
    {
        object? marker = null;

        while (true)
        {
            XrplResponse<object> response = await _client.GRequest<object, AccountTransactionsRequest>(
                new AccountTransactionsRequest(account)
                {
                    LedgerIndexMin = (int)fromLedger,
                    LedgerIndexMax = (int)toLedger,
                    Limit = _pageSize,
                    Forward = forward,
                    Marker = marker,
                },
                cancellationToken).ConfigureAwait(false);

            JsonElement answer = response.Raw.ToJsonElement();

            foreach (LedgerTransaction tx in ParseTransactions(answer))
            {
                yield return tx;
            }

            // The marker goes back to the node as it came; its shape is the node's business.
            marker = answer.TryGetProperty("marker", out JsonElement next) ? next.Clone() : null;

            if (marker is null) yield break;
        }
    }

    public async Task<long?> EarliestLedgerAsync(CancellationToken cancellationToken)
    {
        XrplResponse<object> response = await _client.GRequest<object, ServerInfoRequest>(new ServerInfoRequest(), cancellationToken).ConfigureAwait(false);
        return EarliestAvailableLedger(response.Raw.ToJsonElement());
    }

    public static IReadOnlyList<LedgerTransaction> ParseTransactions(JsonElement answer)
    {
        if (!answer.TryGetProperty("transactions", out JsonElement list) || list.ValueKind != JsonValueKind.Array) return [];

        List<LedgerTransaction> parsed = [];
        foreach (JsonElement record in list.EnumerateArray())
        {
            parsed.Add(ParseRecord(record));
        }

        return parsed;
    }

    /// <summary>One transaction as a node describes it: an account_tx record, or a tx answer, which has the same top level.</summary>
    public static LedgerTransaction ParseRecord(JsonElement record)
    {
        JsonElement tx =
            record.TryGetProperty("tx_json", out JsonElement json) ? json
            : record.TryGetProperty("tx", out JsonElement legacy) ? legacy
            : record;

        string? memoType = null, memoData = null, memoFormat = null;
        if (tx.TryGetProperty("Memos", out JsonElement memos) && memos.ValueKind == JsonValueKind.Array && memos.GetArrayLength() > 0
            && memos[0].TryGetProperty("Memo", out JsonElement memo))
        {
            memoType = Text(memo, "MemoType");
            memoData = Text(memo, "MemoData");
            memoFormat = Text(memo, "MemoFormat");
        }

        string outcome = record.TryGetProperty("meta", out JsonElement meta) ? Text(meta, "TransactionResult") ?? string.Empty : string.Empty;
        bool validated = record.TryGetProperty("validated", out JsonElement flag) && flag.ValueKind == JsonValueKind.True;

        return new LedgerTransaction(
            Hash: (Text(record, "hash") ?? Text(tx, "hash") ?? string.Empty).ToUpperInvariant(),
            LedgerIndex: Number(record, "ledger_index") ?? Number(tx, "ledger_index") ?? 0,
            Account: Text(tx, "Account") ?? string.Empty,
            Succeeded: string.Equals(outcome, "tesSUCCESS", StringComparison.Ordinal),
            Validated: validated,
            MemoTypeHex: memoType,
            MemoDataHex: memoData,
            MemoFormatHex: memoFormat);
    }

    /// <summary>
    /// The low bound of the first range in complete_ledgers: "32570-106738922", or after a gap
    /// "32570-100,5000-106738922". A node with nothing answers "empty", which parses to null —
    /// zero would read as "has everything".
    /// </summary>
    public static long? EarliestAvailableLedger(JsonElement answer)
    {
        if (!answer.TryGetProperty("info", out JsonElement info)) return null;

        string? ranges = Text(info, "complete_ledgers");
        if (string.IsNullOrWhiteSpace(ranges)) return null;

        string firstRange = ranges.Split(',')[0];
        int dash = firstRange.IndexOf('-');
        string lowest = dash > 0 ? firstRange.Substring(0, dash) : firstRange;

        return long.TryParse(lowest.Trim(), out long result) ? result : null;
    }

    private static string? Text(JsonElement json, string name) =>
        json.ValueKind == JsonValueKind.Object && json.TryGetProperty(name, out JsonElement value) && value.ValueKind == JsonValueKind.String
            ? value.GetString()
            : null;

    private static long? Number(JsonElement json, string name) =>
        json.ValueKind == JsonValueKind.Object && json.TryGetProperty(name, out JsonElement value) && value.ValueKind == JsonValueKind.Number && value.TryGetInt64(out long result)
            ? result
            : null;
}
```

```csharp
namespace XrplFile;

public sealed class ReaderOptions
{
    /// <summary>The largest file the reader assembles. Checked against the manifest before any chunk is read.</summary>
    public long MaxBytes { get; init; } = 20_000_000;
}

/// <summary>A manifest together with where it was found.</summary>
public sealed record ManifestRecord(Manifest Manifest, string Writer, long LedgerIndex, string TxHash);

public sealed record ReadResult(Manifest Manifest, string Writer, IReadOnlyList<BlockEntry> Blocks, byte[] Bytes);

/// <summary>
/// Reads a file out of the ledger and verifies every byte against the manifest's root. The
/// algorithm is the one the format document describes, and the browser library repeats it
/// rule for rule; the shared vectors keep the two in step.
/// </summary>
public sealed class XrplFileReader(ILedgerSource source, ReaderOptions? options = null)
{
    private readonly ILedgerSource _source = source;
    private readonly ReaderOptions _options = options ?? new ReaderOptions();

    public async Task<ReadResult> ReadAsync(XrplFileLink link, CancellationToken cancellationToken)
    {
        ManifestRecord record = await ManifestAsync(link, cancellationToken).ConfigureAwait(false);
        Manifest manifest = record.Manifest;

        if (manifest.Size > _options.MaxBytes)
        {
            throw new XrplFileException(XrplFileError.TooLarge, $"the file is {manifest.Size} bytes and this reader stops at {_options.MaxBytes}");
        }

        await RequireHistoryFromAsync(manifest.FirstLedger, cancellationToken).ConfigureAwait(false);

        IReadOnlyList<BlockEntry> blocks = await BlockListAsync(record, cancellationToken).ConfigureAwait(false);

        byte[] bytes = new byte[manifest.Size];
        long at = 0;

        foreach (BlockEntry block in blocks)
        {
            byte[] content = await BlockAsync(record, block, cancellationToken).ConfigureAwait(false);
            int take = (int)Math.Min(content.Length, manifest.Size - at);
            Array.Copy(content, 0, bytes, at, take);
            at += take;
        }

        return new ReadResult(manifest, record.Writer, blocks, bytes);
    }

    public async Task<ManifestRecord> ManifestAsync(XrplFileLink link, CancellationToken cancellationToken)
    {
        LedgerTransaction? tx = await _source.TransactionAsync(link.TxHash, cancellationToken).ConfigureAwait(false);

        if (tx is null)
        {
            long? earliest = await _source.EarliestLedgerAsync(cancellationToken).ConfigureAwait(false);

            if (earliest is null || earliest > Endpoints.MainnetFirstLedger)
            {
                throw new XrplFileException(XrplFileError.NodeLacksHistory,
                    $"the node does not know transaction {link.TxHash} and its history starts at ledger {earliest?.ToString() ?? "an unknown point"}; " +
                    "a node with full history may still have it");
            }

            throw new XrplFileException(XrplFileError.ManifestNotFound, $"no transaction {link.TxHash} on this network");
        }

        if (!tx.Validated || !tx.Succeeded)
        {
            throw new XrplFileException(XrplFileError.ManifestNotFound, $"transaction {link.TxHash} is not a validated, successful transaction");
        }

        if (!MemoLayout.IsManifest(tx.MemoTypeHex) || tx.MemoDataHex is null)
        {
            throw new XrplFileException(XrplFileError.ManifestNotFound, $"transaction {link.TxHash} does not carry an {MemoLayout.ManifestMarker} memo");
        }

        Manifest manifest;

        try
        {
            manifest = Manifest.Decode(MemoLayout.FromHexUtf8(tx.MemoDataHex));
        }
        catch (Exception e) when (e is FormatException or ArgumentException)
        {
            throw new XrplFileException(XrplFileError.CorruptManifest, $"the manifest in {link.TxHash} is unreadable: {e.Message}", inner: e);
        }

        string? inconsistency = manifest.Inconsistency();
        if (inconsistency is not null)
        {
            throw new XrplFileException(XrplFileError.CorruptManifest, $"the manifest in {link.TxHash} is inconsistent: {inconsistency}");
        }

        if (manifest.LastLedger >= tx.LedgerIndex)
        {
            throw new XrplFileException(XrplFileError.CorruptManifest, $"the manifest in {link.TxHash} names a ledger range that ends after the manifest itself");
        }

        return new ManifestRecord(manifest, tx.Account, tx.LedgerIndex, tx.Hash);
    }

    public async Task<IReadOnlyList<BlockEntry>> BlockListAsync(ManifestRecord record, CancellationToken cancellationToken)
    {
        Manifest manifest = record.Manifest;

        if (manifest.Blocks == 1)
        {
            return [new BlockEntry(0, manifest.Root, manifest.FirstLedger)];
        }

        // Backwards from the end of the range: the lists were written after the chunks, so they
        // are the first thing a backward read meets.
        Dictionary<long, string> payloads = [];

        await foreach (LedgerTransaction tx in _source.AccountTransactionsAsync(record.Writer, manifest.FirstLedger, manifest.LastLedger, forward: false, cancellationToken).ConfigureAwait(false))
        {
            if (!IsMine(tx, record.Writer, manifest)) continue;

            long? index = MemoLayout.ListIndexOf(tx.MemoTypeHex);
            if (index is null || tx.MemoDataHex is null) continue;

            // Earlier in ledger order wins, and a backward read meets the later copy first.
            payloads[index.Value] = tx.MemoDataHex;

            if (payloads.Count == manifest.Lists && Enumerable.Range(0, manifest.Lists).All(i => payloads.ContainsKey(i))) break;
        }

        if (payloads.Count != manifest.Lists)
        {
            throw new XrplFileException(XrplFileError.ListMismatch, $"the manifest promises {manifest.Lists} block-list memos and {payloads.Count} were found");
        }

        IReadOnlyList<BlockEntry> entries;

        try
        {
            entries = FileTree.DecodeEntries(Enumerable.Range(0, manifest.Lists).Select(i => MemoLayout.FromHexUtf8(payloads[i])));
        }
        catch (Exception e) when (e is FormatException or ArgumentException)
        {
            throw new XrplFileException(XrplFileError.ListMismatch, $"the block list is unreadable: {e.Message}", inner: e);
        }

        if (entries.Count != manifest.Blocks)
        {
            throw new XrplFileException(XrplFileError.ListMismatch, $"the manifest says {manifest.Blocks} blocks and the list has {entries.Count}");
        }

        string root = FileTree.RootHex(entries);
        if (!string.Equals(root, manifest.Root, StringComparison.Ordinal))
        {
            throw new XrplFileException(XrplFileError.ListMismatch, $"the block list hashes to {root}, the manifest says {manifest.Root}");
        }

        return entries;
    }

    public async Task<byte[]> BlockAsync(ManifestRecord record, BlockEntry block, CancellationToken cancellationToken)
    {
        Manifest manifest = record.Manifest;
        long firstChunk = (long)block.Index * FileTree.BlockChunks;
        long lastChunk = Math.Min(firstChunk + FileTree.BlockChunks, manifest.ChunkCount) - 1;
        int count = (int)(lastChunk - firstChunk + 1);

        byte[]?[] chunks = new byte[count][];
        int found = 0;

        await foreach (LedgerTransaction tx in _source.AccountTransactionsAsync(record.Writer, block.FirstLedger, manifest.LastLedger, forward: true, cancellationToken).ConfigureAwait(false))
        {
            if (!IsMine(tx, record.Writer, manifest)) continue;

            long? index = MemoLayout.ChunkIndexOf(tx.MemoTypeHex);
            if (index is null || index < firstChunk || index > lastChunk || tx.MemoDataHex is null) continue;

            int slot = (int)(index.Value - firstChunk);
            if (chunks[slot] is not null) continue;

            try
            {
                chunks[slot] = MemoLayout.Bytes(tx.MemoDataHex);
            }
            catch (FormatException)
            {
                continue;
            }

            if (++found == count) break;
        }

        if (found != count)
        {
            int missing = Array.FindIndex(chunks, chunk => chunk is null);
            throw new XrplFileException(XrplFileError.ChunkMissing,
                $"chunk {firstChunk + missing} of block {block.Index} is not in ledgers {block.FirstLedger}..{manifest.LastLedger}", block.Index);
        }

        string hash = Convert.ToHexString(FileTree.BlockHash(chunks!));
        if (!string.Equals(hash, block.HashHex, StringComparison.Ordinal))
        {
            throw new XrplFileException(XrplFileError.BlockMismatch,
                $"block {block.Index} hashes to {hash}, the list says {block.HashHex}", block.Index);
        }

        int total = chunks.Sum(chunk => chunk!.Length);
        byte[] bytes = new byte[total];
        int at = 0;

        foreach (byte[]? chunk in chunks)
        {
            Array.Copy(chunk!, 0, bytes, at, chunk!.Length);
            at += chunk.Length;
        }

        return bytes;
    }

    private async Task RequireHistoryFromAsync(long ledger, CancellationToken cancellationToken)
    {
        long? earliest = await _source.EarliestLedgerAsync(cancellationToken).ConfigureAwait(false);

        if (earliest is not null && earliest > ledger)
        {
            throw new XrplFileException(XrplFileError.NodeLacksHistory,
                $"the file starts in ledger {ledger} and the node's history starts at {earliest}; use a node with full history");
        }
    }

    private static bool IsMine(LedgerTransaction tx, string writer, Manifest manifest) =>
        tx.Succeeded && tx.Validated
        && string.Equals(tx.Account, writer, StringComparison.Ordinal)
        && tx.LedgerIndex >= manifest.FirstLedger && tx.LedgerIndex <= manifest.LastLedger;
}
```

```csharp
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;
using Xrpl.Wallet;

namespace XrplFile.Tests;

/// <summary>
/// A sink that validates everything on the spot into a FakeLedgerSource, one hundred
/// transactions per ledger, so the writer's read-back has something to read.
/// </summary>
public sealed class FakeLedgerSink(FakeLedgerSource ledger, long firstLedger = 5000) : ILedgerSink
{
    private readonly List<Dictionary<string, object>> _submitted = [];
    private uint _nextSequence = 10;
    private int _ledgersClosed;

    public IReadOnlyList<Dictionary<string, object>> Submitted => _submitted;

    /// <summary>Which submissions (by position) the node refuses, and with what.</summary>
    public Dictionary<int, string> Refusals { get; } = [];

    /// <summary>Applied to the stored MemoData of the given submission — corrupts the ledger copy without touching what was signed.</summary>
    public Dictionary<int, Func<string, string>> StoredAs { get; } = [];

    public Task<uint> SequenceAsync(string account, bool validated, CancellationToken cancellationToken)
    {
        // A wait for validation is where a real ledger closes; the fake closes one per query, so
        // the manifest lands in a later ledger than the chunks and lists it describes.
        if (validated) _ledgersClosed++;

        return Task.FromResult(_nextSequence);
    }

    public Task<SubmitOutcome> SubmitAsync(Dictionary<string, object> transaction, XrplWallet wallet, CancellationToken cancellationToken)
    {
        int position = _submitted.Count;
        _submitted.Add(transaction);

        string hash = Convert.ToHexString(SHA256.HashData(Encoding.UTF8.GetBytes($"fake:{position}")));

        if (Refusals.TryGetValue(position, out string? refusal))
        {
            return Task.FromResult(new SubmitOutcome(refusal, hash));
        }

        _nextSequence = Convert.ToUInt32(transaction["Sequence"]) + 1;

        string? memoType = null, memoData = null, memoFormat = null;
        if (transaction.TryGetValue("Memos", out object? memos))
        {
            JsonElement first = JsonSerializer.SerializeToElement(memos)[0].GetProperty("Memo");
            memoType = first.TryGetProperty("MemoType", out JsonElement t) ? t.GetString() : null;
            memoData = first.TryGetProperty("MemoData", out JsonElement d) ? d.GetString() : null;
            memoFormat = first.TryGetProperty("MemoFormat", out JsonElement f) ? f.GetString() : null;
        }

        if (memoData is not null && StoredAs.TryGetValue(position, out Func<string, string>? corrupt)) memoData = corrupt(memoData);

        ledger.Add(new LedgerTransaction(
            hash, firstLedger + position / 100 + _ledgersClosed, (string)transaction["Account"], Succeeded: true, Validated: true,
            memoType, memoData, memoFormat));

        return Task.FromResult(new SubmitOutcome("tesSUCCESS", hash));
    }
}
```

```csharp
using Xrpl.Client;
using Xrpl.Client.Json;
using Xrpl.Models.Common;
using Xrpl.Models.Methods;
using Xrpl.Wallet;

namespace XrplFile;

public sealed class XrplClientLedgerSink(IXrplClient client) : ILedgerSink
{
    private readonly IXrplClient _client = client;

    public async Task<uint> SequenceAsync(string account, bool validated, CancellationToken cancellationToken)
    {
        AccountInfo info = await _client.AccountInfo(
            new AccountInfoRequest(account)
            {
                LedgerIndex = new LedgerIndex(validated ? LedgerIndexType.Validated : LedgerIndexType.Current),
            },
            cancellationToken).Typed().ConfigureAwait(false);

        return info.AccountData.Sequence ?? 0;
    }

    public async Task<SubmitOutcome> SubmitAsync(Dictionary<string, object> transaction, XrplWallet wallet, CancellationToken cancellationToken)
    {
        SignatureResult signed = wallet.Sign(transaction);

        XrplResponse<object> response = await _client.GRequest<object, SubmitRequest>(
            new SubmitRequest { TxBlob = signed.TxBlob }, cancellationToken).ConfigureAwait(false);

        JsonElement answer = response.Raw.ToJsonElement();

            answer.TryGetProperty("engine_result", out JsonElement code) ? code.GetString() ?? string.Empty
            : answer.TryGetProperty("error", out JsonElement error) ? "error:" + error.GetString()
            : answer.GetRawText();

        return new SubmitOutcome(outcome, signed.Hash.ToUpperInvariant());
    }
```

```csharp
using Xrpl.Wallet;

namespace XrplFile;

public sealed class WriterOptions
{
    /// <summary>The fee on every transaction. A caller that has asked the network for its open-ledger fee sets this from it.</summary>
    public int FeeDrops { get; init; } = 12;

    public TimeSpan ValidationTimeout { get; init; } = TimeSpan.FromMinutes(3);

    public TimeSpan ValidationPoll { get; init; } = TimeSpan.FromSeconds(1);

    /// <summary>Read everything back through the reader before writing the manifest. On by default; the format does not require it.</summary>
    public bool ReadBack { get; init; } = true;
}

public sealed record PublishProgress(string Stage, long Done, long Total);

public sealed record PublishResult(
    XrplFileLink Link,
    Manifest Manifest,
    string Writer,
    IReadOnlyList<string> ChunkHashes,
    IReadOnlyList<string> ListHashes,
    string ManifestHash);

/// <summary>
/// Puts a file into the ledger the way the reader will later verify it: chunks, then block
/// lists, then a read-back against the root, then the manifest. An upload that breaks half-way
/// leaves junk in an account's history, never a dead link.
/// </summary>
public sealed class XrplFileWriter(ILedgerSink sink, ILedgerSource source, WriterOptions? options = null)
{
    private readonly ILedgerSink _sink = sink;
    private readonly ILedgerSource _source = source;
    private readonly WriterOptions _options = options ?? new WriterOptions();

    public async Task<PublishResult> PublishAsync(
        ReadOnlyMemory<byte> file, string type, string? name, XrplWallet wallet, string network,
        IProgress<PublishProgress>? progress, CancellationToken cancellationToken)
    {
        if (file.IsEmpty) throw new ArgumentException("an empty file has no chunks and no root", nameof(file));
        if (string.IsNullOrWhiteSpace(type)) throw new ArgumentException("a manifest needs a MIME type", nameof(type));

        string writer = wallet.ClassicAddress;
        IReadOnlyList<byte[]> chunks = FileTree.Split(file, MemoLayout.ChunkBytes);
        int blocks = FileTree.BlockCount(chunks.Count);

        uint sequence = await _sink.SequenceAsync(writer, validated: false, cancellationToken).ConfigureAwait(false);

        // Chunks.
        List<string> chunkHashes = new(chunks.Count);
        for (int i = 0; i < chunks.Count; i++)
        {
            chunkHashes.Add(await SubmitMemoAsync(wallet, sequence++, MemoLayout.ChunkMarkerHex(i), MemoLayout.Hex(chunks[i]), null, cancellationToken).ConfigureAwait(false));
            progress?.Report(new PublishProgress("chunks", i + 1, chunks.Count));
        }

        await WaitForValidationAsync(writer, sequence, cancellationToken).ConfigureAwait(false);

        long firstLedger = await LedgerOfAsync(chunkHashes[0], cancellationToken).ConfigureAwait(false);
        long lastLedger = await LedgerOfAsync(chunkHashes[^1], cancellationToken).ConfigureAwait(false);

        // Block entries: hash over the chunks in memory, first ledger from the ledger itself.
        List<BlockEntry> entries = new(blocks);
        for (int block = 0; block < blocks; block++)
        {
            int firstChunk = block * FileTree.BlockChunks;
            List<byte[]> members = [.. chunks.Skip(firstChunk).Take(FileTree.BlockChunks)];
            long ledger = await LedgerOfAsync(chunkHashes[firstChunk], cancellationToken).ConfigureAwait(false);
            entries.Add(new BlockEntry(block, Convert.ToHexString(FileTree.BlockHash(members)), ledger));
        }

        string root = FileTree.RootHex(entries);

        // Block lists, only when there is more than one block.
        List<string> listHashes = [];
        if (blocks > 1)
        {
            IReadOnlyList<string> payloads = FileTree.EncodeEntries(entries);
            for (int j = 0; j < payloads.Count; j++)
            {
                listHashes.Add(await SubmitMemoAsync(wallet, sequence++, MemoLayout.ListMarkerHex(j), MemoLayout.Utf8Hex(payloads[j]), MemoLayout.JsonFormatHex, cancellationToken).ConfigureAwait(false));
                progress?.Report(new PublishProgress("lists", j + 1, payloads.Count));
            }

            await WaitForValidationAsync(writer, sequence, cancellationToken).ConfigureAwait(false);
            lastLedger = Math.Max(lastLedger, await LedgerOfAsync(listHashes[^1], cancellationToken).ConfigureAwait(false));
        }

        Manifest manifest = new(type, file.Length, MemoLayout.ChunkBytes, root, firstLedger, lastLedger, blocks, listHashes.Count, name);

        // Read-back through the same reader a stranger would use, before the link exists.
        if (_options.ReadBack)
        {
            XrplFileReader reader = new(_source, new ReaderOptions { MaxBytes = long.MaxValue });
            ManifestRecord unpublished = new(manifest, writer, lastLedger + 1, string.Empty);
            IReadOnlyList<BlockEntry> published = await reader.BlockListAsync(unpublished, cancellationToken).ConfigureAwait(false);

            long at = 0;
            for (int block = 0; block < published.Count; block++)
            {
                byte[] content = await reader.BlockAsync(unpublished, published[block], cancellationToken).ConfigureAwait(false);

                if (!content.AsSpan().SequenceEqual(file.Span.Slice((int)at, content.Length)))
                {
                    throw new XrplFileException(XrplFileError.BlockMismatch, $"block {block} read back differs from the file", block);
                }

                at += content.Length;
                progress?.Report(new PublishProgress("read-back", block + 1, published.Count));
            }
        }

        // The manifest, last.
        string manifestHash = await SubmitMemoAsync(wallet, sequence++, MemoLayout.ManifestMarkerHex, MemoLayout.Utf8Hex(manifest.Encode()), MemoLayout.JsonFormatHex, cancellationToken).ConfigureAwait(false);
        await WaitForValidationAsync(writer, sequence, cancellationToken).ConfigureAwait(false);
        progress?.Report(new PublishProgress("manifest", 1, 1));

        return new PublishResult(new XrplFileLink(network, manifestHash), manifest, writer, chunkHashes, listHashes, manifestHash);
    }

    private async Task<string> SubmitMemoAsync(XrplWallet wallet, uint sequence, string memoTypeHex, string memoDataHex, string? memoFormatHex, CancellationToken cancellationToken)
    {
        Dictionary<string, object> memo = new() { ["MemoType"] = memoTypeHex, ["MemoData"] = memoDataHex };
        if (memoFormatHex is not null) memo["MemoFormat"] = memoFormatHex;

        Dictionary<string, object> transaction = new()
        {
            ["TransactionType"] = "AccountSet",
            ["Account"] = wallet.ClassicAddress,
            ["Sequence"] = sequence,
            ["Fee"] = _options.FeeDrops.ToString(System.Globalization.CultureInfo.InvariantCulture),
            ["SigningPubKey"] = wallet.PublicKey,
            ["Memos"] = new List<object> { new Dictionary<string, object> { ["Memo"] = memo } },
        };

        SubmitOutcome outcome = await _sink.SubmitAsync(transaction, wallet, cancellationToken).ConfigureAwait(false);

        if (outcome.EngineResult is not ("tesSUCCESS" or "terQUEUED"))
        {
            throw new XrplFileException(XrplFileError.SubmitRefused,
                $"the node answered {outcome.EngineResult} to the transaction at sequence {sequence}");
        }

        return outcome.TxHash;
    }

    /// <summary>Waits until the account's validated sequence reaches the one after the last submission.</summary>
    private async Task WaitForValidationAsync(string account, uint nextSequence, CancellationToken cancellationToken)
    {
        DateTimeOffset deadline = DateTimeOffset.UtcNow + _options.ValidationTimeout;

        while (true)
        {
            uint validated = await _sink.SequenceAsync(account, validated: true, cancellationToken).ConfigureAwait(false);
            if (validated >= nextSequence) return;

            if (DateTimeOffset.UtcNow >= deadline)
            {
                throw new XrplFileException(XrplFileError.ValidationTimeout,
                    $"the validated sequence is {validated} and {nextSequence} was expected after {_options.ValidationTimeout}");
            }

            await Task.Delay(_options.ValidationPoll, cancellationToken).ConfigureAwait(false);
        }
    }

    private async Task<long> LedgerOfAsync(string hash, CancellationToken cancellationToken)
    {
        LedgerTransaction? tx = await _source.TransactionAsync(hash, cancellationToken).ConfigureAwait(false);

        if (tx is null || !tx.Validated)
        {
            throw new XrplFileException(XrplFileError.ValidationTimeout, $"transaction {hash} was accepted but is not in a validated ledger");
        }

        return tx.LedgerIndex;
    }
}
```

```js
    validated: true,
    memoTypeHex: chunkMarkerHex(i),
    memoDataHex: hex(chunk),
    memoFormatHex: null,
  }));

  vector.lists.forEach((payload, j) => ledger.push({
    hash: labelHash(`list:${j}`),
    ledgerIndex: vector.ledger.listLedger,
    account: WRITER,
    succeeded: true,
    validated: true,
    memoTypeHex: listMarkerHex(j),
    memoDataHex: utf8Hex(payload),
    memoFormatHex: JSON_FORMAT_HEX,
  }));

  ledger.push({
    hash: MANIFEST_HASH,
    ledgerIndex: vector.ledger.manifestLedger,
    account: WRITER,
    succeeded: true,
    validated: true,
    memoTypeHex: MANIFEST_MARKER_HEX,
    memoDataHex: utf8Hex(vector.manifest),
    memoFormatHex: JSON_FORMAT_HEX,
  });

  return ledger;
}

/** An in-memory source: insertion order is canonical order within a ledger. */
export class FakeSource {
  constructor(transactions = [], earliest = 1) {
    this.transactions = [...transactions];
    this.earliest = earliest;
    this.accountTransactionsCalls = 0;
  }

  async transaction(hash) {
    return this.transactions.find((tx) => tx.hash.toUpperCase() === hash.toUpperCase()) ?? null;
  }

  async *accountTransactions(account, fromLedger, toLedger, forward) {
    this.accountTransactionsCalls++;
    const matching = this.transactions
      .map((tx, position) => ({ tx, position }))
      .filter(({ tx }) => tx.account === account && tx.ledgerIndex >= fromLedger && tx.ledgerIndex <= toLedger)
      .sort((a, b) => (a.tx.ledgerIndex - b.tx.ledgerIndex) || (a.position - b.position));
    if (!forward) matching.reverse();
    for (const { tx } of matching) yield tx;
  }

  async earliestLedger() {
    return this.earliest;
  }
}
```

```js
/** @param {Uint8Array} bytes */
export function hex(bytes) {
  let out = '';
  for (const b of bytes) out += b.toString(16).padStart(2, '0');
  return out.toUpperCase();
}

/** @param {string} text */
export function unhex(text) {
  if (typeof text !== 'string' || text.length % 2 !== 0 || /[^0-9a-fA-F]/.test(text)) throw new Error('not hex');
  const out = new Uint8Array(text.length / 2);
  for (let i = 0; i < out.length; i++) out[i] = parseInt(text.slice(i * 2, i * 2 + 2), 16);
  return out;
}
```

```js
export class XrplFileError extends Error {
  /** @param {string} code one of the XrplFileError names shared with the .NET library */
  constructor(code, message, { block = null, cause = null } = {}) {
    super(message, cause ? { cause } : undefined);
    this.name = 'XrplFileError';
    this.code = code;
    this.block = block;
  }
}

export const SCHEME = 'xrpl-file';
const PREFIX = `${SCHEME}://`;
const KNOWN = new Set(['mainnet', 'testnet', 'devnet']);

function normalizeNetwork(network) {
  const lower = String(network ?? '').toLowerCase();
  if (KNOWN.has(lower)) return lower;
  // Any other network is named by its NetworkID: digits only, no sign, no leading zero.
  return /^(0|[1-9][0-9]*)$/.test(lower) ? lower : null;
}

function normalizeHash(hash) {
  return /^[0-9a-fA-F]{64}$/.test(hash ?? '') ? hash.toUpperCase() : null;
}

export function parseLink(text) {
  if (typeof text !== 'string' || !text.toLowerCase().startsWith(PREFIX)) {
    throw new XrplFileError('InvalidLink', `an xrpl-file link starts with '${PREFIX}'`);
  }
  const rest = text.slice(PREFIX.length);
  const slash = rest.indexOf('/');
  if (slash <= 0 || slash === rest.length - 1) {
    throw new XrplFileError('InvalidLink', 'an xrpl-file link is the network, a slash and the manifest transaction hash');
  }
  const network = normalizeNetwork(rest.slice(0, slash));
  if (!network) throw new XrplFileError('InvalidLink', `'${rest.slice(0, slash)}' is neither a network name nor a NetworkID`);
  const txHash = normalizeHash(rest.slice(slash + 1));
  if (!txHash) throw new XrplFileError('InvalidLink', 'the transaction hash is not 64 hexadecimal characters');
  return { network, txHash };
}

export function formatLink({ network, txHash }) {
  return `${PREFIX}${network}/${txHash}`;
}
```

`web/src/merkle.mjs`:
```js
// Leaf = SHA256(0x00 ‖ data), node = SHA256(0x01 ‖ left ‖ right); an unpaired element is
// promoted, never duplicated. The same rules as the .NET MerkleTree, held together by the
// shared vectors.
const LEAF_PREFIX = 0x00;
const NODE_PREFIX = 0x01;

async function sha256(bytes) {
  return new Uint8Array(await crypto.subtle.digest('SHA-256', bytes));
}

function prefixed(prefix, ...parts) {
  const out = new Uint8Array(1 + parts.reduce((sum, p) => sum + p.length, 0));
  out[0] = prefix;
  let at = 1;
  for (const part of parts) {
    out.set(part, at);
    at += part.length;
  }
  return out;
}

export async function leaf(data) {
  return sha256(prefixed(LEAF_PREFIX, data));
}

export async function node(left, right) {
  return sha256(prefixed(NODE_PREFIX, left, right));
}

export async function root(hashes) {
  if (hashes.length === 0) throw new Error('a tree needs at least one leaf');
  let level = hashes;
  while (level.length > 1) {
    const next = [];
    for (let i = 0; i + 1 < level.length; i += 2) next.push(await node(level[i], level[i + 1]));
    if (level.length % 2 === 1) next.push(level[level.length - 1]);
    level = next;
  }
  return level[0];
}
```

```js
function indexedMarkerHex(prefix, index) {
  if (!Number.isInteger(index) || index < 0) throw new RangeError('a memo index is never negative');
  const marker = `${prefix}${index}`;
  if (marker.length > MAX_MARKER_BYTES) throw new RangeError(`an index past ${MAX_INDEX_DIGITS} digits does not fit its memo`);

function indexOf(memoTypeHex, prefix) {
  if (!memoTypeHex) return null;
  let marker;
  try { marker = hexUtf8(memoTypeHex); } catch { return null; }
  if (!marker.startsWith(prefix)) return null;
  const digits = marker.slice(prefix.length);
  if (!/^(0|[1-9][0-9]*)$/.test(digits) || digits.length > MAX_INDEX_DIGITS) return null;
  return Number(digits);
}

  if (!memoTypeHex) return false;
  try { return hexUtf8(memoTypeHex) === MANIFEST_MARKER; } catch { return false; }
}

export const blockCount = (chunkCount) => (chunkCount <= 0 ? 0 : Math.ceil(chunkCount / BLOCK_CHUNKS));
export const chunkCount = (size, chunkBytes) => (size <= 0 ? 0 : Math.ceil(size / chunkBytes));

export function split(bytes, chunkBytes) {
  const chunks = [];
  for (let at = 0; at < bytes.length; at += chunkBytes) chunks.push(bytes.subarray(at, Math.min(at + chunkBytes, bytes.length)));
  return chunks;
}

export async function blockHash(chunks) {
  const leaves = [];
  for (const chunk of chunks) leaves.push(await leaf(chunk));
  return root(leaves);
}

  const ordered = [...entries].sort((a, b) => a.i - b.i);
  return hex(await root(ordered.map((e) => unhex(e.h))));
}

const serialize = (wires) => JSON.stringify(wires.map(({ i, h, l }) => ({ i, h, l })));
const byteLength = (text) => new TextEncoder().encode(text).length;

export function encodeEntries(entries) {
  const payloads = [];
  let current = [];
  for (const entry of entries) {
    current.push(entry);
    if (byteLength(serialize(current)) > LIST_BYTES) {
      current.pop();
      payloads.push(serialize(current));
      current = [entry];
    }
  }
  if (current.length > 0) payloads.push(serialize(current));
  return payloads;
}

export function decodeEntries(payloads) {
  const entries = [];
  for (const payload of payloads) {
    let wires;
    try { wires = JSON.parse(payload); } catch (e) { throw new Error('a block-list memo is not a JSON array of entries', { cause: e }); }
    if (!Array.isArray(wires)) throw new Error('a block-list memo is not a JSON array of entries');
    for (const wire of wires) {
      if (typeof wire.h !== 'string' || !/^[0-9a-fA-F]{64}$/.test(wire.h)) throw new Error(`block ${wire.i} carries a hash that is not 32 bytes of hex`);
      if (!Number.isInteger(wire.i) || !Number.isInteger(wire.l)) throw new Error(`block ${wire.i} has a non-integer index or ledger`);
      entries.push({ i: wire.i, h: wire.h.toUpperCase(), l: wire.l });
    }
  }
  if (entries.length === 0) throw new Error('the block list is empty');
  entries.sort((a, b) => a.i - b.i);
  entries.forEach((entry, expected) => {
    if (entry.i !== expected) throw new Error(`the block list is not 0..${entries.length - 1}: found ${entry.i} where ${expected} was expected`);
  });
  return entries;
}
```

```js
import { MANIFEST_BYTES, CHUNK_BYTES, blockCount, chunkCount } from './tree.mjs';

export const MANIFEST_VERSION = 1;

const byteLength = (text) => new TextEncoder().encode(text).length;

function serialize(m, name) {
  const fields = { v: MANIFEST_VERSION, type: m.type, size: m.size, chunk: m.chunk, root: m.root, ledgers: [m.firstLedger, m.lastLedger], blocks: m.blocks, lists: m.lists };
  if (name != null) fields.name = name;
  return JSON.stringify(fields);
}

/** One character off the end — a whole code point, so a surrogate pair is not cut in half. */
function shortenByOneCharacter(value) {
  const points = [...value];
  points.pop();
  return points.join('');
}

export function encodeManifest(m) {
  let name = m.name ?? null;
  for (;;) {
    const json = serialize(m, name);
    if (byteLength(json) <= MANIFEST_BYTES) return json;
    if (!name) throw new Error('the manifest does not fit its memo even without a name');
    name = shortenByOneCharacter(name);
    if (name.length === 0) name = null;
  }
}

const isInt = (v) => Number.isInteger(v);

export function decodeManifest(json) {
  let m;
  try { m = JSON.parse(json); } catch (e) { throw new Error(`the manifest does not parse as JSON: ${e.message}`, { cause: e }); }
  if (m === null || typeof m !== 'object' || Array.isArray(m)) throw new Error('the manifest is not a JSON object');
  if (!isInt(m.v)) throw new Error('the manifest has no version');
  if (m.v !== MANIFEST_VERSION) throw new Error(`manifest version ${m.v} is not one this library reads`);
  if (typeof m.type !== 'string') throw new Error('the manifest has no type');
  if (!isInt(m.size)) throw new Error('the manifest has no size');
  if (!isInt(m.chunk)) throw new Error('the manifest has no chunk size');
  if (typeof m.root !== 'string' || !/^[0-9a-fA-F]{64}$/.test(m.root)) throw new Error('the manifest root is not 64 hex characters');
  if (!isInt(m.blocks)) throw new Error('the manifest has no block count');
  if (!isInt(m.lists)) throw new Error('the manifest has no list count');
  if (!Array.isArray(m.ledgers) || m.ledgers.length !== 2) throw new Error('the manifest ledgers are not a pair');
  const [firstLedger, lastLedger] = m.ledgers;
  if (!isInt(firstLedger) || !isInt(lastLedger) || firstLedger <= 0 || lastLedger < firstLedger) throw new Error('the manifest ledger range is not ascending');
  return {
    type: m.type, size: m.size, chunk: m.chunk, root: m.root.toUpperCase(), firstLedger, lastLedger,
    blocks: m.blocks, lists: m.lists, name: typeof m.name === 'string' ? m.name : null,
  };
}

/** Why the counts do not agree with one another, or null when they do. */
export function inconsistency(m) {
  if (m.size < 0) return `the size ${m.size} is negative`;
  if (m.chunk <= 0 || m.chunk > CHUNK_BYTES) return `a chunk of ${m.chunk} bytes is outside 1..${CHUNK_BYTES}`;
  if (m.lists < 0) return `the list count ${m.lists} is negative`;
  const chunks = chunkCount(m.size, m.chunk);
  const expectedBlocks = blockCount(chunks);
  if (m.blocks !== expectedBlocks) return `the manifest says ${m.blocks} blocks, ${chunks} chunks make ${expectedBlocks}`;
  if ((m.lists === 0) !== (m.blocks === 1)) return `the manifest says ${m.blocks} blocks and ${m.lists} list memos, and a single block is the only file without a list`;
  return null;
}
```

```js
// Block k of the stream is SHA256(seed ‖ k as a big-endian uint32); blocks concatenated, cut to size.
export async function vectorBytes(seed, size) {
  const seedBytes = new TextEncoder().encode(seed);
  const input = new Uint8Array(seedBytes.length + 4);
  input.set(seedBytes, 0);
  const output = new Uint8Array(size);
  let at = 0;
  let counter = 0;
  while (at < size) {
    input[input.length - 4] = (counter >>> 24) & 0xff;
    input[input.length - 3] = (counter >>> 16) & 0xff;
    input[input.length - 2] = (counter >>> 8) & 0xff;
    input[input.length - 1] = counter & 0xff;
    const block = new Uint8Array(await crypto.subtle.digest('SHA-256', input));
    const take = Math.min(block.length, size - at);
    output.set(block.subarray(0, take), at);
    at += take;
    counter++;
  }
  return output;
}
```

```js
  const lowest = Number.parseInt(dash > 0 ? first.slice(0, dash) : first, 10);

export class LedgerClient {
  /** @param {string[]} endpoints tried in order; each operation moves on when a node fails */
  constructor(endpoints, { pageSize = 400 } = {}) {
    if (!endpoints?.length) throw new Error('at least one endpoint is required');
    this.endpoints = endpoints;
    this.pageSize = pageSize;
    this.index = 0;
    this.socket = null;
    this.nextId = 1;
    this.pending = new Map();
    this.closed = false;
  }

  get endpoint() { return this.endpoints[this.index]; }

  close() {
    this.closed = true;
    this.disconnect();
  }

  disconnect() {
    if (this.socket) {
      this.socket.onclose = null;
      this.socket.onmessage = null;
      try { this.socket.close(); } catch { /* already closed */ }
      this.socket = null;
    }
    for (const { reject, timer } of this.pending.values()) {
      clearTimeout(timer);
      reject(new XrplFileError('NodeUnreachable', `connection to ${this.endpoint} closed while a request was in flight`));
    }
    this.pending.clear();
  }

  async connect() {
    if (this.closed) throw new XrplFileError('NodeUnreachable', 'this client has been closed');
    if (this.socket?.readyState === WebSocket.OPEN) return;
    await new Promise((resolve, reject) => {
      const socket = new WebSocket(this.endpoint);
      socket.onopen = () => { this.socket = socket; resolve(); };
      socket.onerror = () => reject(new XrplFileError('NodeUnreachable', `cannot reach ${this.endpoint}`));
      socket.onclose = () => { if (this.socket === socket) this.disconnect(); };
      socket.onmessage = (event) => this.receive(JSON.parse(event.data));
    });
  }

  receive(message) {
    const waiting = this.pending.get(message.id);
    if (!waiting) return;
    this.pending.delete(message.id);
    clearTimeout(waiting.timer);
    if (message.status === 'error') waiting.resolve({ error: message.error, ...message });
    else waiting.resolve(message.result);
  }

  /** One request, tried on each endpoint in turn; the answer is the node's result object. */
  async request(command, params) {
    let lastError = null;
    for (let attempt = 0; attempt < this.endpoints.length; attempt++) {
      try {
        await this.connect();
        return await this.send(command, params);
      } catch (e) {
        if (this.closed || e.code !== 'NodeUnreachable') throw e;
        lastError = e;
        this.disconnect();
        this.index = (this.index + 1) % this.endpoints.length;
      }
    }
    throw lastError;
  }

  send(command, params) {
    return new Promise((resolve, reject) => {
      const id = this.nextId++;
      const timer = setTimeout(() => {
        this.pending.delete(id);
        reject(new XrplFileError('NodeUnreachable', `${this.endpoint} did not answer ${command} in ${REQUEST_TIMEOUT_MS} ms`));
      }, REQUEST_TIMEOUT_MS);
      this.pending.set(id, { resolve, reject, timer });
      this.socket.send(JSON.stringify({ id, command, api_version: 2, ...params }));
    });
  }

  async transaction(hash) {
    const answer = await this.request('tx', { transaction: hash });
    if (answer.error === 'txnNotFound') return null;
    if (answer.error) throw new XrplFileError('NodeUnreachable', `${this.endpoint} answered ${answer.error} to tx`);
    return parseRecord(answer);
  }

  async *accountTransactions(account, fromLedger, toLedger, forward) {
    let marker;
    for (;;) {
      const answer = await this.request('account_tx', {
        account, ledger_index_min: fromLedger, ledger_index_max: toLedger, forward, limit: this.pageSize, ...(marker ? { marker } : {}),
      });
      if (answer.error) throw new XrplFileError('NodeUnreachable', `${this.endpoint} answered ${answer.error} to account_tx`);
      for (const record of answer.transactions ?? []) yield parseRecord(record);
      marker = answer.marker;
      if (!marker) return;
    }
  }

  async earliestLedger() {
    return earliestAvailableLedger(await this.request('server_info', {}));
  }
}
```

```js
import { XrplFileError } from './link.mjs';
import { MAINNET_FIRST_LEDGER } from './ledger.mjs';
import { BLOCK_CHUNKS, isManifest, chunkIndexOf, listIndexOf, decodeEntries, rootHex, blockHash, chunkCount } from './tree.mjs';
import { decodeManifest, inconsistency } from './manifest.mjs';
import { hex, unhex, hexUtf8 } from './hex.mjs';

/**
 * Reads a file out of the ledger and verifies every byte against the manifest's root — the
 * .NET XrplFileReader's algorithm, rule for rule.
 */
export class XrplFileReader {
  /** @param source anything with transaction(hash), accountTransactions(account, from, to, forward), earliestLedger() */
  constructor(source, { maxBytes = 20_000_000 } = {}) {
    this.source = source;
    this.maxBytes = maxBytes;
  }

  async read(link, onProgress = () => {}) {
    const record = await this.manifest(link);
    const manifest = record.manifest;

    if (manifest.size > this.maxBytes) {
      throw new XrplFileError('TooLarge', `the file is ${manifest.size} bytes and this reader stops at ${this.maxBytes}`);
    }

    await this.requireHistoryFrom(manifest.firstLedger);

    const blocks = await this.blockList(record);
    const bytes = new Uint8Array(manifest.size);
    const chunksTotal = chunkCount(manifest.size, manifest.chunk);
    let at = 0;
    let chunksDone = 0;

    for (const block of blocks) {
      const content = await this.block(record, block, () => onProgress({ chunksDone: ++chunksDone, chunksTotal }));
      const take = Math.min(content.length, manifest.size - at);
      bytes.set(content.subarray(0, take), at);
      at += take;
    }

    return { manifest, writer: record.writer, blocks, bytes };
  }

  async manifest(link) {
    const tx = await this.source.transaction(link.txHash);

    if (tx === null) {
      const earliest = await this.source.earliestLedger();
      if (earliest === null || earliest > MAINNET_FIRST_LEDGER) {
        throw new XrplFileError('NodeLacksHistory',
          `the node does not know transaction ${link.txHash} and its history starts at ledger ${earliest ?? 'an unknown point'}; a node with full history may still have it`);
      }
      throw new XrplFileError('ManifestNotFound', `no transaction ${link.txHash} on this network`);
    }

    if (!tx.validated || !tx.succeeded) throw new XrplFileError('ManifestNotFound', `transaction ${link.txHash} is not a validated, successful transaction`);
    if (!isManifest(tx.memoTypeHex) || tx.memoDataHex === null) throw new XrplFileError('ManifestNotFound', `transaction ${link.txHash} does not carry an xf/m memo`);

    let manifest;
    try {
      manifest = decodeManifest(hexUtf8(tx.memoDataHex));
    } catch (e) {
      throw new XrplFileError('CorruptManifest', `the manifest in ${link.txHash} is unreadable: ${e.message}`, { cause: e });
    }

    const problem = inconsistency(manifest);
    if (problem) throw new XrplFileError('CorruptManifest', `the manifest in ${link.txHash} is inconsistent: ${problem}`);
    if (manifest.lastLedger >= tx.ledgerIndex) throw new XrplFileError('CorruptManifest', `the manifest in ${link.txHash} names a ledger range that ends after the manifest itself`);

    return { manifest, writer: tx.account, ledgerIndex: tx.ledgerIndex, txHash: tx.hash };
  }

  async blockList(record) {
    const manifest = record.manifest;
    if (manifest.blocks === 1) return [{ i: 0, h: manifest.root, l: manifest.firstLedger }];

    // Backwards from the end of the range: the lists were written after the chunks.
    const payloads = new Map();
    for await (const tx of this.source.accountTransactions(record.writer, manifest.firstLedger, manifest.lastLedger, false)) {
      if (!isMine(tx, record.writer, manifest)) continue;
      const index = listIndexOf(tx.memoTypeHex);
      if (index === null || tx.memoDataHex === null) continue;
      payloads.set(index, tx.memoDataHex);   // earlier in ledger order wins; a backward read meets the later copy first
      if (payloads.size === manifest.lists && [...Array(manifest.lists).keys()].every((i) => payloads.has(i))) break;
    }

    if (payloads.size !== manifest.lists) throw new XrplFileError('ListMismatch', `the manifest promises ${manifest.lists} block-list memos and ${payloads.size} were found`);

    let entries;
    try {
      entries = decodeEntries([...Array(manifest.lists).keys()].map((i) => hexUtf8(payloads.get(i))));
    } catch (e) {
      throw new XrplFileError('ListMismatch', `the block list is unreadable: ${e.message}`, { cause: e });
    }

    if (entries.length !== manifest.blocks) throw new XrplFileError('ListMismatch', `the manifest says ${manifest.blocks} blocks and the list has ${entries.length}`);
    const root = await rootHex(entries);
    if (root !== manifest.root) throw new XrplFileError('ListMismatch', `the block list hashes to ${root}, the manifest says ${manifest.root}`);
    return entries;
  }

  async block(record, entry, onChunk = () => {}) {
    const manifest = record.manifest;
    const firstChunk = entry.i * BLOCK_CHUNKS;
    const lastChunk = Math.min(firstChunk + BLOCK_CHUNKS, chunkCount(manifest.size, manifest.chunk)) - 1;
    const count = lastChunk - firstChunk + 1;
    const chunks = new Array(count).fill(null);
    let found = 0;

    for await (const tx of this.source.accountTransactions(record.writer, entry.l, manifest.lastLedger, true)) {
      if (!isMine(tx, record.writer, manifest)) continue;
      const index = chunkIndexOf(tx.memoTypeHex);
      if (index === null || index < firstChunk || index > lastChunk || tx.memoDataHex === null) continue;
      const slot = index - firstChunk;
      if (chunks[slot] !== null) continue;
      try { chunks[slot] = unhex(tx.memoDataHex); } catch { continue; }
      onChunk();
      if (++found === count) break;
    }

    if (found !== count) {
      const missing = chunks.indexOf(null);
      throw new XrplFileError('ChunkMissing', `chunk ${firstChunk + missing} of block ${entry.i} is not in ledgers ${entry.l}..${manifest.lastLedger}`, { block: entry.i });
    }

    const h = hex(await blockHash(chunks));
    if (h !== entry.h) throw new XrplFileError('BlockMismatch', `block ${entry.i} hashes to ${h}, the list says ${entry.h}`, { block: entry.i });

    const total = chunks.reduce((sum, c) => sum + c.length, 0);
    const bytes = new Uint8Array(total);
    let at = 0;
    for (const chunk of chunks) { bytes.set(chunk, at); at += chunk.length; }
    return bytes;
  }

  async requireHistoryFrom(ledger) {
    const earliest = await this.source.earliestLedger();
    if (earliest !== null && earliest > ledger) {
      throw new XrplFileError('NodeLacksHistory', `the file starts in ledger ${ledger} and the node's history starts at ${earliest}; use a node with full history`);
    }
  }
}

function isMine(tx, writer, manifest) {
  return tx.succeeded && tx.validated && tx.account === writer && tx.ledgerIndex >= manifest.firstLedger && tx.ledgerIndex <= manifest.lastLedger;
}
```

````markdown
# xrpl-file, version 1

A link format for files stored inside the XRP Ledger, and the layout that makes such a file
readable and verifiable from the link alone.

This document is normative for version 1. The words MUST, MUST NOT, SHOULD and MAY are used as
in RFC 2119. The reference implementations are `XrplFile.Core` (.NET) and `web/xrpl-file.js`
(browser) in this repository; `tests/vectors/v1.json` holds test vectors both are held to.

## 1. Link

```
xrpl-file://<network>/<tx-hash>
```

- `network` MUST be one of `mainnet`, `testnet`, `devnet`, or the decimal `NetworkID` of another
  XRPL-protocol network without a leading zero. Names are case-insensitive; the canonical form is
  lower case.
- `tx-hash` MUST be the 64-character hexadecimal hash of the manifest transaction (section 4).
  It is case-insensitive; the canonical form is upper case.
- A link MUST NOT carry a query string, a fragment, or anything after the hash.

The canonical link is 84 bytes. Hex-encoded into an NFT `URI` it uses 168 of the 256 bytes
rippled allows.

## 2. Transactions

A file is written by one account, the *writer*, as a series of transactions each carrying one
memo. The writer SHOULD use `AccountSet` with no fields other than the memo; a reader MUST NOT
depend on the transaction type.

| Kind | `MemoType` (decoded) | `MemoData` | `MemoFormat` (decoded) | Data budget |
|---|---|---|---|---|
| chunk | `xf/c/<i>` | raw file bytes | absent | 1000 bytes |
| block list | `xf/b/<j>` | JSON array of block entries | `application/json` | 982 bytes |
| manifest | `xf/m` | JSON object | `application/json` | 995 bytes |

`<i>` and `<j>` are decimal indices from 0 with no leading zeros and at most 12 digits. A
marker that does not match this exactly is not a marker.

The budgets follow from rippled's limit of 1024 bytes on the serialized `Memos` array: a memo
carrying only `MemoData` costs 5 bytes of framing; a `MemoType` or `MemoFormat` costs 2 bytes
plus its own length. With the longest marker (17 bytes) a 1000-byte chunk serializes to exactly
1024 bytes.

The writer MUST write chunks first, then block lists, then the manifest last.

## 3. Chunks and the tree

The file is cut into chunks of `chunk` bytes (section 4), the last one shorter. Version 1
writers MUST use `chunk` = 1000; readers MUST accept any `chunk` from 1 to 1000. The chunk count
is `ceil(size / chunk)`.

Hashing uses SHA-256 with domain separation:

- leaf = `SHA256(0x00 || chunk bytes)`, over exactly the bytes in `MemoData`;
- node = `SHA256(0x01 || left || right)`;
- the root over a list of hashes pairs them left to right; an unpaired element at any level
  is promoted to the next level unchanged. It is never duplicated.

Chunks group into **blocks** of 1024 by index: block `b` holds chunks `1024·b` to
`1024·b + 1023`. A block's hash is the root over its chunks' leaves in index order. The file's
`root` is the root over the block hashes in block order. A file of one block has `root` equal
to its block hash.

## 4. Manifest

`MemoData` of the manifest transaction is a JSON object:

```json
{"v":1,"type":"image/png","size":734512,"chunk":1000,
 "root":"<64 hex>","ledgers":[106497159,106497394],
 "blocks":1,"lists":0,"name":"cover.png"}
```

| Field | Required | Meaning |
|---|---|---|
| `v` | yes | format version, `1` |
| `type` | yes | MIME type of the file |
| `size` | yes | file length in bytes, ≥ 0 |
| `chunk` | yes | chunk payload size the writer used |
| `root` | yes | the file root, 64 hex characters |
| `ledgers` | yes | `[first, last]`: the range of validated ledgers holding every chunk and every block list, `0 < first ≤ last` |
| `blocks` | yes | `ceil(chunkCount / 1024)` |
| `lists` | yes | number of block-list transactions; `0` if and only if `blocks` = 1 |
| `name` | no | file name |

The manifest MUST be written in a ledger after `last`. Writers SHOULD emit the fields in the
order above without whitespace and SHOULD shorten `name` by whole characters until the JSON
fits 995 bytes, dropping it if nothing fits.

A reader MUST reject a manifest whose fields are missing, mistyped, whose `v` is not 1, whose
`root` is not 64 hex characters, whose ledger range is not ascending, whose `blocks` does not
equal `ceil(ceil(size / chunk) / 1024)`, or whose `lists` is zero exactly when `blocks` ≠ 1 is
false.

## 5. Block list

When `blocks` > 1 the writer MUST publish the block list: entries
`{"i":<block>,"h":"<block hash, 64 hex>","l":<ledger of the block's first chunk>}` packed
greedily into JSON arrays of at most 982 bytes, one array per `xf/b/<j>` transaction, entries
in block order across the transactions. When `blocks` = 1 there is no list and a reader uses
the single entry `{i: 0, h: root, l: first}`.

A reader MUST reject a list whose indices are not exactly `0..blocks-1`, whose hashes are not
64 hex characters, or whose root over the block hashes differs from the manifest's `root`.

## 6. Reading

Given a link:

1. Fetch the manifest transaction by hash. It MUST be validated, MUST have result `tesSUCCESS`
   and MUST carry an `xf/m` memo; the *writer* is its `Account`.
2. Validate the manifest (section 4).
3. Obtain the block list (section 5), reading the writer's transactions in `[first, last]`.
4. For each block, read the writer's transactions from the block's `l` up to `last` and collect
   its chunks by the chunk rule below. Hash the block and compare with its entry.
5. Concatenate the blocks and cut to `size`.

**Chunk rule.** A transaction is chunk `i` when all of the following hold: its `Account` is
the writer; it is validated with result `tesSUCCESS`; its ledger is within `[first, last]`;
its first memo's `MemoType` decodes to `xf/c/<i>`; and `MemoData` is present. A transaction of
the writer that does not match is not a chunk and not an error. If several transactions
qualify for the same `i`, the earliest in canonical ledger order is the chunk.

A reader MUST NOT deliver bytes of a block whose hash does not match its entry, and SHOULD
report the block index.

### Nodes

Reading needs a node that holds the ledgers in `[first, last]` and the manifest's ledger.
Public nodes with full history exist on mainnet (`xrplcluster.com`, `s2.ripple.com`); not every
node keeps full history. When a node does not know the manifest's hash, a reader SHOULD
consult `server_info.complete_ledgers`: a node whose history does not start at the network's
first ledger (32570 on mainnet) may simply not hold it.

## 7. Writing

A writer MUST submit chunks with their markers, then block lists (when `blocks` > 1), then the
manifest, in that order, and MUST NOT write the manifest until every earlier transaction is
validated. It MUST NOT resubmit an index with different bytes. It SHOULD read the file back by
section 6 before writing the manifest.

## 8. Limits

| | |
|---|---|
| chunk payload | 1000 bytes |
| block | 1024 chunks |
| block list transaction | ≤ 982 bytes of JSON |
| manifest | ≤ 995 bytes of JSON |
| index | ≤ 12 decimal digits |
| file size | unbounded by the format |

## 9. Test vectors

`tests/vectors/v1.json` gives, for each of several file sizes, a seed and the derived hashes,
block list and manifest. The file bytes are regenerated, not stored: block `k` of the stream is
`SHA256(UTF8(seed) || k as a big-endian uint32)`, blocks concatenated and cut to `size`. The
vectors also fix the Merkle known answers shared with the XRPL video platform.

## 10. NFT usage

An NFT's `URI` MAY be an xrpl-file link to an XLS-24 metadata JSON whose `image` or
`animation_url` is itself an xrpl-file link. Readers resolve each hop by section 6. The
metadata MAY additionally carry `image_gateway` with an HTTPS URL for clients that only
understand HTTP; a reader never needs it.
````

````markdown
# xrpl-file

A link that points at a file stored inside the XRP Ledger, and the tools to write and read one.

```
xrpl-file://mainnet/9F2C0B7D1E4A6C8B3D5F7A9C1E3B5D7F9A1C3E5B7D9F1A3C5E7B9D1F3A5C7E9B
```

An NFT's `URI` usually points at IPFS, and IPFS content lasts only as long as somebody pins it.
The ledger entry is permanent; the thing it names is not. An xrpl-file link names a *manifest*
transaction; the manifest names the ledger range holding the file's bytes in memos, and a
Merkle root to verify them. Nothing to pin, nothing to expire, and every byte checked.

The format is specified in [docs/spec/xrpl-file-v1.md](docs/spec/xrpl-file-v1.md). The design
and its reasoning are in [docs/superpowers/specs](docs/superpowers/specs).

## What is here

| | |
|---|---|
| `src/XrplFile.Core` | .NET library: parse a link, read and verify a file, publish one. On top of the [`Xrpl`](https://www.nuget.org/packages/Xrpl) package |
| `web/xrpl-file.js` | the same reading in dependency-free browser JavaScript |
| `tests/vectors/v1.json` | vectors both implementations are held to |
| `tools/XrplFile.Vectors` | regenerates the vectors from the .NET code |

A command-line uploader, an HTTP gateway, a demo page and an embeddable `<xrpl-file>` element
are planned next.

## Reading a file (.NET)

```csharp
using Xrpl.Client;
using XrplFile;

IXrplClient client = new XrplClient("wss://xrplcluster.com");
await client.Connect();

XrplFileReader reader = new(new XrplClientLedgerSource(client));
ReadResult file = await reader.ReadAsync(XrplFileLink.Parse("xrpl-file://mainnet/…"), CancellationToken.None);

Console.WriteLine($"{file.Manifest.Type}, {file.Bytes.Length} bytes, root {file.Manifest.Root}");
```

## Reading a file (browser)

```js
import { LedgerClient, ENDPOINTS, XrplFileReader, parseLink } from './web/xrpl-file.js';

const link = parseLink('xrpl-file://mainnet/…');
const reader = new XrplFileReader(new LedgerClient(ENDPOINTS[link.network]));
const { manifest, bytes } = await reader.read(link, ({ chunksDone, chunksTotal }) => console.log(chunksDone, chunksTotal));
```

## Publishing a file (.NET)

```csharp
XrplWallet wallet = XrplWallet.FromSeed(Environment.GetEnvironmentVariable("XRPL_SEED")!);
XrplFileWriter writer = new(new XrplClientLedgerSink(client), new XrplClientLedgerSource(client));

PublishResult published = await writer.PublishAsync(
    File.ReadAllBytes("cover.png"), "image/png", "cover.png", wallet, "mainnet", progress: null, CancellationToken.None);

Console.WriteLine(published.Link);
```

The writer sends one `AccountSet` per 1000 bytes, then the block list, reads everything back,
and only then writes the manifest. A run that breaks half-way leaves no link behind.
````
