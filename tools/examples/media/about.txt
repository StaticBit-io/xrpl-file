English
xrpl-file keeps a file in the XRP Ledger. The file is cut into chunks, and each chunk is written in a transaction. A link points at the manifest that lists them. A browser reads the chunks back and checks them against the fingerprint, and nothing is stored on a server of ours.

Русский
