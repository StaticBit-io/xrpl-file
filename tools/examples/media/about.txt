English
xrpl-file keeps a file in the XRP Ledger. The file is cut into chunks, and each chunk is written in its own transaction. A link points at the manifest, which holds the fingerprint of the whole list of blocks. A browser reads the chunks back and checks them against that fingerprint. Our server takes no part in reading.
