Self-hosted web font: Geologica, licensed under the SIL Open Font License 1.1 (see Geologica-OFL.txt).
No other font file ships with the site; values such as hashes use the visitor's system monospace face,
and Chinese text falls back to the system CJK fonts (see --font-body in css/tokens.css).

Source: github.com/google/fonts, directory ofl/geologica (commit a60a77e of that path, 2026-03-03),
upstream https://github.com/googlefonts/geologica by Monokrom (Sindre Bremnes, Frode Helland).

Derived files (built with fontTools 4.62 + brotli; the design is not modified):
  1. fontTools.varLib.instancer: wght limited to 200-500, SHRP kept 0-100, CRSV pinned 0, slnt pinned 0
     (the site uses neither the cursive nor the slanted axis, so they are dropped).
  2. fontTools.subset to the two Unicode ranges below, woff2, all layout features kept, hinting removed.
