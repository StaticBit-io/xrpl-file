Eine Datei im XRP Ledger speichern

Das Bild Ihres Tokens oder jede andere Datei: in dasselbe Ledger geschrieben wie der Token und beim Lesen anhand ihres Fingerabdrucks geprüft.

Die Windows-App, die Ihre Dateien in das Ledger schreibt.

Links zu Metadaten verschwinden

Speichert ein NFT, ein MPT, eine DID oder ein Credential sein Bild und seine Beschreibung außerhalb des Ledgers, enthält der Ledger-Eintrag nur einen Link. Die Datei liegt auf IPFS, auf dem eigenen Server des Ausstellers oder in einem S3-Bucket.

  • IPFS ohne PinningDas Pinning wird nicht mehr bezahlt, und die Datei verschwindet aus IPFS.
  • Ein abgeschalteter ServerDas Unternehmen schließt oder zieht um, und die Adresse antwortet mit einem Fehler.
  • Ein geschlossener BucketDas Speicherkonto wird geschlossen, und die Dateien verschwinden mit ihm.

Dieser Eintrag bleibt im Ledger, doch die Datei hinter seinem Link kann verloren gehen. Mit xrpl-file wird die Datei in dasselbe Ledger geschrieben, in Transaktionen, die sich nicht ändern oder löschen lassen, und jeder kann sie anhand ihres Fingerabdrucks prüfen, ohne einem Server zu vertrauen. Der xrpl-file-Link ist 84 Byte lang, das URI-Feld eines NFT fasst 256.

Von der Datei zum Link und zurück

  1. In Chunks zerlegt

    Die Datei wird in Stücke von je 1000 Byte zerlegt, sogenannte Chunks.

  2. Als Transaktionen geschrieben

    Jeder Chunk wird in eine eigene Transaktion geschrieben, in das Memo-Feld.

  3. Mit Fingerabdruck

    Je 1024 Chunks bilden einen Block, und der Hash des Blocks kommt in eine Blockliste. Eine letzte Transaktion, das Manifest, enthält den Fingerabdruck der ganzen Liste. Der Hash dieser Transaktion ist der Link.

  4. Gelesen und geprüft

    Wer den Link hat, holt die Chunks von einem Knoten des XRP Ledger, setzt die Datei zusammen und prüft jeden Block anhand seines Fingerabdrucks. Eine Datei, die nicht zu ihrem Fingerabdruck passt, wird nicht angezeigt. Der Server dieser Website ist daran nicht beteiligt.

Was es kostet

Eine Datei kommt mit etwa einer Transaktion pro Kilobyte in das Ledger. Für jede Datei legt die Publisher-App ein Einmalkonto an und löscht es, sobald die Datei geschrieben ist. Es gibt zwei Arten von Kosten. Gebühren werden verbraucht. Eine Reserve ist gebunden, solange die Datei geschrieben wird, und der größte Teil der Reserve kommt zurück.

Die Preistabelle ist gerade nicht verfügbar. Die Zahlen stehen auch in der Datendatei price.json.

Dauerhaft und öffentlich

Es lässt sich nicht löschen

Was ins Ledger geschrieben ist, bleibt dort. Niemand kann es löschen oder ändern, Sie und wir eingeschlossen.

Jeder kann es lesen

Jeder kann die Datei lesen. Die Daten des Ledgers sind für alle offen, und der Link ist kein Geheimnis.

Veröffentlichen Sie nur, was Sie der ganzen Welt für immer zeigen möchten: kein Passwort, keine persönlichen Daten, kein Bild, das Sie nicht weitergeben dürfen.
