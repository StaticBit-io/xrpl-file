把文件存入 XRP Ledger

代币的图片或任何其他文件，写入与代币相同的账本，读取时按指纹校验。

立方体显示一个真实文件的分片是如何从账本中读取的。每个数据块都按指纹校验通过后，文件本身会出现在它们旁边。

把你的文件写入账本的 Windows 应用。

指向元数据的链接会失效

当 NFT、MPT、DID 或凭证把图片和描述存放在账本之外时，账本中的条目只保存一个链接。文件则放在 IPFS 上、发行方自己的服务器上或 S3 存储桶中。

  • 未固定（pin）的 IPFS固定服务停止付费后，文件就会从 IPFS 中消失。
  • 服务器关闭公司关闭或搬迁后，原地址只会返回错误。
  • 存储桶被关闭存储账户被关闭，文件也随之消失。

这个条目会一直留在账本里，但链接背后的文件可能丢失。使用 xrpl-file 时，文件被写入同一个账本，写入文件的交易无法修改或删除，任何人都可以按指纹校验文件，无需信任任何服务器。xrpl-file 链接为 84 字节，而 NFT 的 URI 字段可容纳 256 字节。

从文件到链接，再回到文件

  1. 切成分片

    文件被切成若干块，每块 1000 字节，称为分片。

  2. 写成交易

    每个分片写入各自的交易，放在备注（Memo）字段中。

  3. 生成指纹

    每 1024 个分片组成一个数据块，数据块的哈希进入数据块列表。最后一笔交易称为清单，其中保存整个列表的指纹。这笔交易的哈希就是链接。

  4. 读取并校验

    任何拿到链接的人都可以从 XRP Ledger 节点取得分片，拼出文件，并按指纹校验每个数据块。与指纹不符的文件不会显示。本站服务器不参与这一过程。

费用

文件写入账本时，大约每千字节对应一笔交易。发布每个文件时，发布工具都会开设一个一次性账户，并在文件写完后将其删除。费用分为两类。手续费会被花掉。储备金在文件写入期间被锁定，其中大部分会退回。

价格表暂时无法显示。数据也可以在数据文件 price.json 中查看。

永久且公开

无法删除

写入账本的内容会一直留在那里。任何人都无法删除或修改，你和我们也一样。

任何人都能读取

任何人都可以读取这个文件。账本上的数据对所有人公开，链接也不是秘密。

只发布你愿意永久向全世界公开的内容：不要发布密码、个人信息，或你无权分享的图片。
