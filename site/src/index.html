Links to metadata die

An NFT, an MPT, a DID or a credential usually does not hold its picture or its description. It holds a link, and the file sits somewhere else: on IPFS, on the issuer’s own server, in an S3 bucket.

  • IPFS without pinningPinning stops being paid for, and the file drops out of IPFS.
  • A closed serverThe company shuts down or moves, and the address answers with an error.
  • A lapsed bucketThe storage account is closed, and the files go with it.

The token stays in the ledger. Its picture does not. With xrpl-file the file is written into the same ledger as the token, so it lives as long as the token does, and anyone can check it against its fingerprint without trusting a server. The link to it is 84 bytes, and an NFT’s URI field holds 256.

From a file to a link, and back

  1. Cut into chunks

    The file is cut into pieces of 1000 bytes.

  2. Written as transactions

    Each piece goes into its own transaction, attached to it as a memo.

  3. Fingerprinted

    Every 1024 chunks form a block, and the block’s hash goes into a block list. One last transaction, the manifest, holds the fingerprint of the whole list. The hash of that transaction is the link.

  4. Read and checked

    Whoever has the link collects the chunks from an XRP Ledger node, assembles the file and checks every block against its fingerprint. A file that does not match is not shown. This site’s server takes no part in it.

What it costs

A file goes into the ledger as roughly one transaction per kilobyte. For each file the publisher opens a throwaway account and deletes it when the file is written. There are two costs: fees, which are spent, and a reserve, which is held while the file is written and mostly comes back.

The price table is not available right now. The figures are also in the data file, price.json.

Permanent and public

It cannot be deleted

What is written into the ledger stays there. Nobody can delete or change it, you and we included.

Anyone can read it

No account, no permission, no password. Anyone who has the link can read the file, and the data of the ledger is open to everyone anyway.

Publish only what you are glad to show the whole world for good: not a password, not personal data, not a picture you have no right to share.

The one exception is the test network, where the first picture on this page lives. It is reset from time to time, and its files go with it.
