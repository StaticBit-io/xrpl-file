Файл внутри самого XRP Ledger

Картинка вашего токена или любой другой файл записываются в тот же реестр, что и токен, а читаются с проверкой по отпечатку.

Картинка рядом: настоящий файл из реестра. Браузер проверяет его по частям и показывает, только когда каждая часть сошлась.

Приложение для Windows, которое записывает ваши файлы в реестр.

Ссылки на метаданные умирают

Токен XRP Ledger (NFT или MPT), DID или удостоверение обычно не хранят свою картинку и описание. Они хранят ссылку, а сам файл лежит в другом месте: в IPFS, на сервере эмитента, в корзине S3.

  • IPFS без закрепленияЗакрепление перестают оплачивать, и файл пропадает из IPFS.
  • Закрытый серверКомпания закрывается или переезжает, и по адресу приходит ошибка.
  • Закрытое хранилищеАккаунт в облаке закрывают, и файлы исчезают вместе с ним.

Токен остаётся в реестре. Его картинка нет. С xrpl-file файл записан в тот же реестр, что и токен, поэтому живёт столько же, сколько он, а проверить его по отпечатку может любой, не доверяя ничьему серверу. Ссылка на файл занимает 84 байта, а поле URI у NFT вмещает 256.

От файла до ссылки и обратно

  1. Нарезка

    Файл режется на фрагменты по 1000 байт.

  2. Запись в транзакции

    Каждый фрагмент уходит в отдельную транзакцию и прикрепляется к ней как заметка (memo).

  3. Отпечаток

    Каждые 1024 фрагмента образуют блок, а хэш блока попадает в список блоков. Последняя транзакция, манифест, хранит отпечаток всего списка. Хэш этой транзакции и есть ссылка.

  4. Чтение и проверка

    Тот, у кого есть ссылка, собирает фрагменты с узла XRP Ledger, склеивает файл и сверяет каждый блок с отпечатком. Файл, который не сошёлся, не показывается. Сервер этого сайта в чтении не участвует.

Сколько это стоит

Файл попадает в реестр примерно по одной транзакции на килобайт. Для каждого файла публикатор открывает одноразовый аккаунт и удаляет его, когда файл записан. Расходов два: комиссии, которые тратятся, и резерв, который удерживается, пока файл записывается, и почти весь возвращается.

Таблица цен сейчас недоступна. Цифры есть и в файле данных price.json.

Навсегда и для всех

Удалить нельзя

Записанное в реестр остаётся в нём. Удалить или изменить его не может никто, ни вы, ни мы.

Читать может любой

Ни аккаунта, ни разрешения, ни пароля. Файл прочтёт любой, у кого есть ссылка, а данные реестра и так открыты всем.

Публикуйте только то, что готовы показывать всему миру навсегда: не пароли, не личные данные, не картинку, права на которую у вас нет.
