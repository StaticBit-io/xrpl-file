<xrpl-file> demo

Testnet files read straight from the ledger and verified in your browser. Elements below the fold start when you scroll near them (loading="lazy"). The log at the end lists load, error and xrpl-file-progress for every element. The light and auto themes, on a light and on a dark page, are on themes.html.

Loading

loading="eager": starts at once, without waiting to come near the viewport.

Image

The file downloads completely and every block is verified before it is shown.

Text

Plain text, a large text file, and HTML shown as text, never rendered.

Download

Types the page does not draw itself: SVG (never inlined) and HEVC video (not playable in most browsers) offer a verified download.

Video

MP4 with the index at the start or the end, fragmented MP4, WebM, one with a cover, one whose cover is broken (ignored), and the large one.

loading="click"

Only the manifest and the cover are read up front; the content loads when you press the button.

loader="false"

The reserved space stays empty until the content is ready, for sites that draw their own placeholder.

Sizing

Presentational width and height attributes, then a CSS grid of three that sizes the elements from the page's own stylesheet (180px high): picture, picture-blocks, text.

Errors

Each of these ends in an error state and fires error.

Small sizes

The element lays itself out by its own width: from 240px as usual, from 120px to 239px in a compact form (one line per text, a short button, a one-line caption), under 120px as icons. The rows below set width to 50, 100, 160 and 300px; the last one also sets a 40px height from the page's own style. Hover a box to see its caption.

width="50"

width="100"

width="160"

width="300"

width="160", style="height:40px"

Events

Newest first. Progress is one line per element, updated in place.
